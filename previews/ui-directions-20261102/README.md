# 주요 화면 UI 구성안 · 2026-11-02

`../lobby-direction/` 로비를 기준으로 만든 16개 화면의 독립 HTML/CSS 디자인 검토본. 실제 게임 규칙과 저장 데이터는 변경하지 않는다.

- `index.html`: 전체 화면 비교 / 한 화면씩 보기 / 직접 열기
- `screen.html?view=battle`: 개별 화면 (review.js의 화면 목록 참조)
- `design.css`: 공통 토큰, 버튼, 카드, 헤더, 스크롤 본문, 고정 푸터
- `screens.js`: 화면 예시와 탭·선택·화면 이동 인터랙션

## 공통 규칙

배경 #211b2a, 패널 #2c2433, 본문 #f1e6d7, 보조 #b5a4bd, 주요 행동 #e8bb68. 선 1px, 모서리 3~7px, 화면 패딩 16px, 카드 패딩 14px, 기본 간격 8/12/16px. 일반 버튼 44px, 주요 버튼 50px. 본문 13~14px, 제목 20px. 캐릭터·아이콘은 기존 애셋을 참조한다. 패널 장식은 CSS 핀과 얇은 선으로 제한한다.

화면은 viewport 높이 안에 고정. 본문만 스크롤하고 헤더·확정 행동·GNB는 별도 행에 둔다. 이미지화한 문구나 이미지 버튼을 사용하지 않는다. 화력·재화·확률은 검토용 예시이며 실제 적용 시 게임 데이터를 연결한다. 지원 영웅은 역할명을 임시 표기한다. 구매·편성 변경·훈련은 실제 게임을 변경하지 않는다.

## 화면

당직실, 전투, 직원 도감, 인사기록, 지원 영웅, 상점, 채용 결과, 훈련소, 이야기 도감, 프롤로그, 장비, 보너스, 일시정지, 결과, 기록·편성, 설정.
