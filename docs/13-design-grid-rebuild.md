# 원본 화면 격자 재구성

기준 원본은 `designs/skin-v2/screens-gobi-v2/`의 17개 이미지(941×1672)입니다.
이전 검수는 넘침 여부에 치우쳤으며, 가로 장식 패널을 여러 비율로 늘리면서 원본과 프레임·카드 구조가 달라진 문제를 놓쳤습니다.

## 재구성

`design-grid.css`가 화면별 좌표와 구성 영역을 정의합니다. 기존 일러스트와 실제 게임 로직은 유지합니다.
프레임은 원본 모서리·변을 SVG로 나누고 CSS border-image로 두께를 고정합니다. 글자·가격·기록·잠금 상태는 실제 DOM에서 갱신됩니다.
`scripts/build-design-grid-assets.py`로 SVG 자산을 재생성할 수 있습니다.

## 의도적으로 유지한 기능 차이

- 사용자 요청인 GNB 3개와 지원 용병 안의 5인 근무 명단 유지.
- 직원/용병 종류·이름·가격·소환 비용·현재 기록은 실제 게임 데이터 사용. 원화의 예시 숫자로 고정하지 않음.
- 도감은 원화의 가짜 필터/페이지 버튼 대신 실제 전체 목록 스크롤과 현재 필터 유지.
- 결과의 직원별 통계와 최고 등급은 펼침 영역에서 볼 수 있음.
- 연수, 보너스, 저장 실패/재시도, 잠긴 직원 등 추가 상태도 같은 프레임 사용.

## 검증

- 기본 17개 + 전투·잠금·상세 등 총 52개 상태를 브라우저에서 확인.
- DOM 좌표는 원본 크기 941×1672에서 측정. 캡처 도구의 높이 제한 때문에 전체 캡처는 740×1315에서 저장.
- 320×740에서 기본 17개 화면을 별도 검수. 버튼/명단/상품/대사 패널의 scrollWidth·scrollHeight 넘침 항목 0개.
- 도감 열기→편성 해제→다시 추가→5명 복원 확인.
- 실제 전투 일시정지→계속→장비 열기→경비원 Lv.1→Lv.2 강화 확인.
- 새 검사 탭 콘솔 실행 오류 없음. 게임 테스트 7개 통과.
- QA 문서는 로컬 전용이며 저장소를 분리함. 공개 사이트에 검사 스크립트나 저장소 대체 코드는 배포하지 않음.

산출물: `qa/design-grid-pass/`. 모든 상태·모바일 캡처와 원본 대조 갤러리를 포함합니다.
완전한 픽셀 동일성 검증을 주장하지 않으며, 위 원본 영역과 실제 콘텐츠의 배치·프레임 재구성을 검증했습니다.
