# 메인과 이어지는 만화풍 플레이 화면

승인한 파란 성곽·노란 소환 버튼 시안을 실제 게임에 반영했다. [실제 화면과 상태별 검수](../qa/comic-battle-20261110/index.html) · [배포용 전신 갤러리](../assets/battle-comic/gallery.html).

## 화면 구성

- 웨이브·생명·속도·일시정지: 진한 남색 상단 HUD와 크림색 버튼. 수치는 기존 상태에서 갱신한다.
- 안내: 기존 전체 안내 열기 동작을 유지한다. 진행 표시는 실제 대기열·생존 적 수와 다음 공격 대기시간을 사용한다.
- 보드: 파란 성곽 안뜰, 밝은 포장 이동로, 5열×3행 전신 배치. 배경에는 글자·캐릭터·그리드를 그려 넣지 않았다. 이동로와 칸은 실제 `path`·`cells`로 그린다.
- 하단: 선택 직원 초상·스킬·등급, 실제 재사용 대기 진행, SP·소환·장비 강화, 소비 아이템 3종 순서다.
- 소비 아이템: 이름을 시각적으로 숨기고 기존 아이콘·수량·사용 가능 여부·선택 테두리를 표시한다. 스크린리더 이름과 수량, 44px 이상 터치 영역은 유지한다.
- 모든 게임 수치·이름·버튼 문구는 DOM/Canvas 텍스트다. 영문판을 위해 배경 이미지에 텍스트를 넣지 않았다.

## 아군 전신

메뉴 얼굴만 떠 있던 보드 표시를 전신 모션으로 바꿨다. 직원 17명 전원이 대기·눈깜빡임·준비·공격·스킬·회복의 6포즈를 사용한다. 고비·찌릿은 직전 승인 전신을 유지하고, 나머지 15명은 현재 공통 얼굴과 기존 직업·도구를 참조해 같은 만화풍 전신을 제작했다. 메뉴의 얼굴 중심 초상은 유지한다.

브릭의 남색 초승달 투구·금색 볏, 토르크의 곱슬머리·큰 웃음과 고글 없는 얼굴, 뽀득의 모자 없는 물방울 머리, 루프의 흰 유령 얼굴 등 메뉴와 다른 인물처럼 보이던 요소를 맞췄다. 찌릿은 스토리의 주황 점박이 도마뱀·작업모·보라 작업복·꼬리를 유지한다.

`assets/character-motion/manifest.js`가 직원 ID별 전신·6프레임·바닥 기준점·대체 이미지를 정의한다. 보드와 직원 컷인은 이 모션을 사용한다. 지원 영웅은 기존 전신 모션을 유지한다. 6포즈 전체의 최대 크기로 안전 영역을 계산해 동작이 바뀌어도 인접 칸·상태 글자에 침범하지 않도록 한다.

## 기존 적과 이펙트

적군 6종·군단장 모션 원화는 그대로 활용한다. 새 보드에서 적을 구분하기 쉽도록 표시 크기와 배지 대비만 조정했다. 기존 투사체·연쇄 번개·범위 공격·상태 이상·도착·합성 성공/실패·지원 효과·마왕 연출의 코드를 유지한다. 스킬 컷인은 새 전신을 쓰며 아군 연출의 색상과 이미지 확대 방식을 정리했다.

좌표 600×600, 배치 인덱스, 경로, 공격 판정·범위·확률·가격·쿨다운·저장 형식·입력 핸들러는 변경하지 않았다. 기존 투명 입력 Canvas와 화면 투영을 유지한다. 훈련·연습 모드에서는 기존처럼 소환/소비 아이템을 숨긴다.

## 소스와 재수출

- 승인 시안·새 배경·15명 전신 원본: `designs/battle-comic-20261110/`.
- 고비·찌릿 원본: `designs/battle-identity-20261110/`.
- 전신 재수출: `python scripts/export-matching-battle-sprites.py` (Pillow와 ImageMagick). 원본 알파 경계를 측정하고 WebP·프레임·체크섬을 만든다. 직접 그림을 그리는 스크립트가 아니다.
- 배경: `courtyard-master.png`를 1024×1024 WebP quality 92로, 하단 바닥은 배경의 `700x220+150+620` 영역을 추출해 quality 90으로 내보냈다.
- 배포: 코드·WebP·공개 애셋 갤러리만 포함하며 PNG 원본과 QA 자료는 제외한다.

## 검증

Node 78개, 배포 패키지 Chromium 검사 20개 통과. 모든 직원이 실제 Canvas에서 전신 모션 파일로 그려지고 얼굴 파일로 돌아가지 않는지, 적군이 기존 모션을 사용하는지 검사한다. 이름 없는 아이템 버튼의 접근성 이름·44px 터치 영역·선택/취소와 재고 불변도 검사한다.

17명×6포즈×4크기 = 408조합에서 직원 픽셀/상태 글자 충돌 0건, 상태 글자·그리드 문제 0건. 320×568·390×640·390×844·430×932의 전투·아이템 선택·일시정지에서 DOM 기하 문제, 스크립트 오류·누락 자산 0건이다. 15칸 밀집 상태와 브릭·고비·찌릿 전신 컷인도 캡처했다. 화면 캡처는 실제 렌더러의 결정된 테스트 상태이며, 게임을 진행하는 기능 검사는 별도로 수행했다.

공개 주소 직접 재촬영은 실행 환경의 프록시 제한으로 수행하지 못한다. 같은 소스의 배포 패키지와 GitHub 배포 결과를 확인한다. [기계 판독 요약](../qa/comic-battle-20261110/summary.json).
