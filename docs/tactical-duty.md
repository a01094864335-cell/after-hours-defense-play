# 전략 선택과 짧은 당직 완료 경험

2026-11-06. 리뷰 비교에서 제안한 여섯 가지 개선을 적용했다. 기존 재화·영구 훈련·직원 능력·튜토리얼을 유지하며 다음 선택을 추가한다.

## 적용 규칙

| 개선 | 실제 동작 |
| --- | --- |
| 재배치 | 정식 당직 준비 중, 보스 보상의 ‘전열 정비’에서 직원을 빈 칸으로 이동한다. 드래그 또는 직원→빈 칸 선택을 지원한다. 교환·전투 중 자유 이동은 제공하지 않는다. 등급·스킬 대기시간 등 직원 객체를 그대로 보존한다. |
| 합성 미리보기 | 드래그 대상 위에 결과 등급·성공률·종류 변경을 표시한다. 일반 탭/키보드 선택도 호환 대상의 결과 등급이 같으면 미리 표시한다. 등급이 섞인 특수 합성은 대상을 드래그할 때 정확히 표시한다. |
| 종류 유지 | 보스 보상과 교환해 다음 유효한 합성 1회를 성공시키고 도착 직원의 종류를 유지한다. 보유 상한은 1회다. 무효 입력은 소비하지 않고 기존 합성 성공 보장도 함께 소비하지 않는다. |
| 당직 전략 | 기존 보스 보상의 대안으로 한 당직에 하나만 선택한다. ‘연쇄 잔광’은 0.8초마다 거리 140 안의 추가 적에 피해 25%, ‘정산 특근’은 서기 자동 수입·회계 정산 +25%, ‘비상 방벽’은 첫 돌파 1회 방어다. 정산 특근은 해당 직원/지원이 편성된 경우 선택한다. |
| 자발적 퇴근 | 정식 당직 15·30·45…웨이브의 적을 모두 막은 보상 창에서 퇴근할 수 있다. 현재 누적 보상을 기존 정산 경로로 확정한다. 계속할 때는 기존 보상 또는 전략을 선택하며 다음 공격으로 넘어간다. 중간 입금이나 새 화폐는 추가하지 않는다. |
| 초반 선택·체험 | 연수 수료 후 미채용 일반 직원 후보 3명 중 1명을 한 번 무료 채용한다. 기존 수료 이용자도 미채용 직원이 있으면 동일한 1회 기회를 받는다. 먼저 5등급 직원의 실제 전투와 스킬을 1웨이브 체험할 수 있다. 선택은 자동 편성을 바꾸지 않는다. |
| 시각 피드백 | 지원 직원 선택 시 인접 영향 칸, 치유 사제 발동 시 회복 범위·연결선, 드래그 합성 대상 칸을 강조한다. 결과에는 마지막 돌파 적의 아이콘과 이름을 표시하며 패배 원인이라고 단정하지 않는다. |

튜토리얼에서는 재배치·전략·종류 유지·자발적 퇴근을 해제하지 않아 기존 실습 흐름을 보존한다. 준비/정비 안내와 짧은 카드만 표시하며 상세 규칙은 근무 안내·보상 규칙에 접어둔다.

## 저장·보상 안전성

- 기존 지갑과 전투 버전은 유지하고 선택 필드를 추가한다. 과거 저장의 `tactics`는 기본값, `profile.starterClaim`은 미수령으로 이관한다.
- 선택한 전략·종류 유지 횟수·방벽 소비·연쇄 대기시간·완료 웨이브를 저장한다. 잘못된 형식과 미완료 전투의 완료 표기는 적용 전에 거부한다.
- 정비 중 재접속하면 변경된 배치는 유지하고 보스 보상 창으로 돌아간다.
- 퇴근은 기존 runId 정산 중복 방지·미지급 보상 복구를 사용한다. 기록의 완료 웨이브는 실제 퇴근한 보스 웨이브다.
- 무료 채용의 소유권과 수령 표시는 하나의 지갑 저장으로 확정한다. 실패하거나 이미 수령했으면 중복 지급하지 않는다.
- 전투 체험은 `fresh=1` 메모리 저장을 사용하는 별도 프레임에서 실제 게임 엔진을 실행한다. 본 창의 지갑·진행 전투는 바꾸지 않으며 닫으면 프레임을 제거한다. 로그인·클라우드 동기화 기능은 추가하지 않았다.

## 검증

- 런타임 68개 통과: 신규 14개에서 이동 제한·객체 보존·종류 유지·전략 효과·복원·무료 채용·정산 실패 복구·중복 지급을 검사한다.
- 배포 빌드 브라우저 11개 통과: 기존 8개에 격리 체험의 실제 스킬과 본 저장 보존, 정비 후 전략 이어하기, 퇴근 정산 재접속을 추가했다. CI 필수 검사에 포함한다.
- 신규 흐름은 320×568 / 390×844 / 430×932에서 실제 터치·마우스로 확인한다. 카드와 버튼의 텍스트 겹침·모달 경계 검사와 캡처를 포함한다.
- 기존 전체 화면·스크롤 상태 135개에서 레이아웃 오류 없음. 성능 회귀 검사 8개 통과. 이는 실기기 발열·배터리 검증을 뜻하지 않는다.
- 48개 자동 전투는 3개 덱 × 기본/3전략 × 4시드, 훈련 Lv.1·마왕/아이템/일일 변주 제외 조건이다. 5차에 전략을 고르는 고정 정책이며 각 전략 조건 12판 중 11판에서 실제 선택에 도달했다. 기본 평균 23.67, 연쇄 24.00, 정산 22.33, 방벽 24.92웨이브였다. 모두 정상 패배로 종료했고 수치 오류/실행 상한 도달은 없었다.
- 이 작은 표본은 인간 플레이나 최강 전략 검증이 아니다. 전략이 첫 보스 SP 보상을 대체하는 기회비용과 난수 소비 차이를 포함한다. 이후 실제 선택률·재도전·조합별 결과를 보고 조정한다.
