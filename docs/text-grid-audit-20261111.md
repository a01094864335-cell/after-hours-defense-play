## 한글·영문 검수의 의미

현재 게임에는 완성된 별도 영문판이나 언어 전환 기능이 없다. 이번 작업은 다음을 구분한다.

- **ko:** 실제 한글 UI와 게임 데이터로 검수했다.
- **en:** UI 번역 문구 후보를 일회용 테스트 페이지에 적용했다. 긴 이름·제목·가격·설명의 레이아웃을 확인하는 용도이며, 미번역 이야기·스킬 설명이 남아 있을 수 있다. `english-fixture.cjs`와 `english-extra.json`에서 후보 문구를 재현할 수 있다.
- **en-stress:** 후보가 없는 본문에는 명시적인 영문 길이 샘플을 사용하고, 실제 계산된 글꼴 크기를 한 번만 130%로 확대한다. 기본 화면 56종(추가 구매 상태 3종을 넣기 전)과 인물/이야기 83종에도 전수 스트레스를 수행했다. 실제 출시 번역을 검증했다는 의미가 아니다. 한국어 원문을 임의의 영문 설명으로 바꿔 출시하지 않는다.

영문 후보 및 스트레스 코드는 배포 게임에 언어 전환 기능으로 싣지 않는다. 실제 적용하는 것은 공통 안전 여백, 영문 길이를 수용하는 CSS, 무문자 배너, DOM 제목과 기존 기능 보존이다. 영문 정식 번역을 넣은 후에는 모든 이야기·스킬·시스템 설명을 다시 검수해야 한다.

## 확인 범위

- 기본 화면·탭·상태 54종 × 4크기 × 한글/영문 후보 = 432건의 기본 매트릭스. 첫 방문·큰 잔액·구매 가능/보장 직전/11코인 부족을 보강한 최종 기본 범위는 59종 × 4크기 × 2언어 = 472건이며 누락은 0건이다. 수정한 도감·이야기 등은 별도 재검수했다.
- 크기: 320×568, 390×684, 390×844, 430×932. 화면 밖으로 정상 스크롤된 내용과 실제 잘림을 구별했다.
- 직원·지원 영웅 24명 상세, 성 이야기 40종, 채용 이야기 19종의 공통 패널을 추가 캡처했다. 이야기는 각 에피소드에서 직렬화한 패널 데이터 길이가 가장 큰 패널을 대표로 선택한다. 모든 삽화의 모든 페이지를 전수 번역한 것은 아니다.
- 편성·도감·변주·이야기 목록·훈련 효과·설명 펼침은 중간 스크롤 구간도 캡처한다. 상단과 하단만으로 긴 목록 전체를 통과 처리하지 않는다.
- 일시정지·중도 이탈·보너스·장비·신입 선택·연습 미리보기·백업 검증·저장 미리보기·정산, 실제 다중 탭 잠금·가로 회전 안내·이야기 갤러리도 포함한다.
- 기록/편성 보관함은 최신 main에서 제거된 진입 화면이므로 새 페이지로 복원하지 않았다. 저장 데이터 보존 정책은 유지한다.

원시 측정은 겹침 **후보**다. 뒤에 가려진 전투 HUD, 스크롤 밖의 글자, 마왕 등장 연출, 기울어진 로고의 축 정렬 사각형은 실제 텍스트 충돌로 단정하지 않는다. 수정 항목은 캡처와 계산된 CSS, 실제 입력으로 확인한다.

## 요약 문구의 원칙

짧게 해도 되는 것은 기능 제목·탭·버튼이다. 예: `Prepare for the Night Shift` 대신 `Start Shift`, `Individual Consumable Items` 대신 `Items`, `Tonight’s Five-Person Duty Roster` 대신 `Duty Roster`.

가격, 구매 개수, 확률, 미보유 보장, 재사용 시간, 무료 여부, 복원/초기화 결과는 의미를 생략하지 않는다. 긴 조건은 버튼에 모두 넣는 대신 바로 옆 설명·잔액 행·펼침 상세로 분리한다. 직원의 정식 이름은 임의로 바꾸지 않고, 영어 카드의 구조를 먼저 바꾼다. `[copy-budgets.json]`의 줄 수는 권장 목표이며 내용을 자르는 하드 제한이 아니다.

## 영문 출시 전 남은 항목

1. 영문 후보를 확정 번역으로 승인하고 실제 런타임 문자열 카탈로그/언어 선택에 연결해야 한다. 이번 패치는 영어판이 출시됐다는 의미가 아니다.
2. 이야기 40종·채용 이야기 19종의 전체 대사, 직원별 스킬 설명, 동적 시스템 안내를 완역한 뒤 다시 캡처해야 한다. 이번 영문 후보에 남은 한글은 보고서의 `untranslatedVisible`에서 확인한다.
3. 메인 한글 로고는 영문용 DOM 워드마크를 준비했다. 상점 배너는 무문자로 교체했다. 일부 이야기 원화의 한글 말풍선은 별도 무문자 원화 또는 정식 영문 애셋이 필요하다. 캡처에서 보이는 사례를 근거로 표시하며 모든 원화에 문자가 있다고 단정하지 않는다.
4. Canvas의 직원 이름은 검수 픽스처에서 영문 후보로 바꿔 확인하지만 전투 메시지 전체가 정식 다국어화된 상태는 아니다.
5. 실제 iOS/Android 기기의 글꼴·브라우저 안전 영역과 영문 접근성 이름은 출시 번역 적용 후 최종 기기 검수가 필요하다. 이번 결과는 Chromium 기준이다.

## 구현·재현·검증

- `text-grid.css`: 마지막 공통 레이어. 일반 DOM과 4개 아트 Shadow DOM에 같은 안전 여백/영문 대응 규칙을 적용한다.
- `text-grid.js`: 기존 노드·핸들러를 유지한다. 무문자 상점 배너/DOM 제목·영문 로고 영역·로비 제목 축약·중복 안내 처리만 추가한다. Shadow DOM 스타일은 빌드된 CSS의 해시 URL을 재사용한다.
- `designs/text-grid-20261111/`: 배너 원본과 생성한 무문자 마스터. 배포에는 `assets/text-grid/shop-hero-wordless.webp`만 사용한다.
- `scripts/text-grid/`: 상태 목록, 실제 렌더러 캡처, 텍스트 측정, 영문 후보/스트레스, 예외 화면·긴 대사 추가 검수 도구.
- 테스트는 도감 제목이 닫기를 가리지 않는지, 짧은 훈련 화면의 피해 비교, 상점 실제 구매, 큰 잔액의 원수치 보존, 긴 대사 이후 실제 다음 페이지 입력을 확인한다.
- Node 3,257개·최종 브라우저 36개 통과. 재검수 우선 선택 후 803개 상태(한글 322·영문 후보 319·영문 스트레스 162), 캡처 1,559장을 보관했다. 채택한 캡처의 페이지 실행 오류는 0건이다. 원시 사각형 후보가 전부 0이라는 뜻은 아니다. 상세 수치는 `summary.json`과 CI 결과를 기준으로 확인한다. 자동 사각형 검사만으로 미감을 승인하지 않는다.

```sh
node scripts/build-pages.cjs /tmp/text-grid-pages
python -m http.server 8042 --directory /tmp/text-grid-pages
UI_QA_DIR=qa/text-grid-20261111/final UI_BASE_URL=http://127.0.0.1:8042/ GRID_LANGS=ko,en GRID_SIZES=320x568,390x684,390x844,430x932 node scripts/text-grid/capture.cjs
UI_BASE_URL=http://127.0.0.1:8042/ GRID_ALL_SCROLLS=1 GRID_FILTER='roster|daily|deck|training-all-effects|info-expanded|story-owned' node scripts/text-grid/capture.cjs
```

기존 전투 규칙·구매·훈련·확률·가격·보장·보상·저장 형식은 바꾸지 않는다. 모든 캡처는 격리된 테스트 브라우저에서 만들었고 실제 플레이어의 기록이나 코인을 사용하지 않는다.

## CI 브라우저 차이 후속 보완

첫 PR의 반복 검사에서 320px 한글 도감 카드의 `편성 중` 회전 도장이 본문 폭을 소량 넘는 경우가 확인됐다. 로컬 Chromium에서는 허용 오차 안이었으나 CI Chromium에서 폭 검사가 실패해 배포가 보류됐다. 도장 양옆에 6px 폭 예산을 예약하고 회전각·패딩을 줄여 실제 인물/이름은 유지했다. 기존 폭 검사 기준을 낮추지 않았고, 회전된 도장의 양끝이 본문 안에 1px 이상 들어오는 검사도 추가했다.

같은 CI 화면 검수에서 390/430px 상점의 구매 버튼 아래 테두리가 스크롤 경계를 약 3px 벗어나는 경우도 확인했다. 상점 본문에 18px 스크롤 안전 여백과 구매 버튼의 스크롤 마진을 추가해 GNB 위로 버튼 전체가 드러나도록 했다. 기존 `fullyVisible` 판정은 유지한다.
