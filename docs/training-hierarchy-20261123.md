# 훈련소 버튼 위계 단순화

사용자 요청: 캐릭터별로 어떤 강화가 발생하는지 훈련 화면에서 일일이 볼 필요가 없으므로 버튼 위계를 정리한다.

- `직원 강화 / 지원 영웅 강화` 그룹 선택과 하단의 노란 `강화하기 · 비용`만 남겼다. 그룹 선택은 파랑/회색의 보조 선택으로, 코인을 소비하는 강화는 노란 주 행동으로 구분한다.
- `훈련 / 캐릭터별 효과` 두 번째 탭 줄, 캐릭터별 상세 목록, 해금 단계 사다리, 특정 캐릭터 초상화와 예시 수치를 훈련 화면에서 제거했다. 숨겨진 상세 컨테이너는 기존 어댑터 호환을 위해 남기지만 새 화면 어댑터의 상세 카드 DOM을 더 생성하지 않는다. 숨겨진 기존 렌더러는 호환을 위해 유지한다.
- 직원은 공통 레벨과 현재→다음 공격 피해만 요약한다. 지원 영웅은 서로 효과가 다르므로 특정 회계사의 SP 예시를 전체 지원 성장처럼 보여주지 않고 공통 레벨만 표시한다.
- 적용 범위 안내는 한 줄(짧은 영문은 두 줄)로 유지한다. 보유 코인과 부족액/강화 후 잔액은 한 번씩만 노출한다. 전투 중 잠금·저장 오류는 계속 안내한다.
- 비용·강화량·레벨 상한·해금 규칙·훈련 저장·전투 잠금·장착 조건은 변경하지 않는다. 캐릭터별 설명은 기존 직원 상세의 성장 영역에서 볼 수 있다.
- 320×568, 390×844, 430×932의 한·영 각각 두 그룹, 12상태를 실제 배포 빌드에서 캡처했다. 기존 바닥 접지와 44px 조작 범위, 큰 글씨에서의 스크롤 대체 동작을 유지한다.

이 문서의 화면이 [전체 애셋 검토](art-review-20261123.md)의 훈련소 캡처보다 나중의 최종 구성이다. 이전 자료는 전후 비교를 위해 유지한다. 공개 호스트 접근 제한으로 캡처는 공식 Pages 패키지를 로컬에서 실행한 결과다. 최종 배포와 전체 반복 검사 결과는 연결된 PR/Actions에 기록한다.

검증 시 이전 훈련 그림의 240px/85px 고정 높이를 강제하던 소스 검사 한 건을 발견했다. 이번 바닥 하단 정렬과 실제 버튼 간격 검사에 맞춰 기대값을 갱신했다. 훈련소에서 제거한 상세 탭에 클릭하던 브라우저 검사도 실제 그룹 선택·강화·저장 동작을 검증하도록 갱신했다.
