## 용량과 메모리

전투 아틀라스 17종·대체 전신·아이템 3개·공통 글꼴의 합계다. 전체 게임 다운로드 용량을 뜻하지 않는다.

| 항목 | 수정 전 | 수정 후 | 절감 |
| --- | ---: | ---: | ---: |
| 위 애셋 묶음 | 9,656,438 B | 4,792,992 B | 50.36% |
| 전신 모션 아틀라스 | 7,074,028 B | 3,915,698 B | 44.65% |
| 아틀라스 RGBA 추정 | 106,954,752 B | 43,273,824 B | 59.54% |
| 공통 글꼴 | 998,424 B | 190,600 B | 80.91% |
| 아이템 아이콘 합계 | 570,448 B | 73,008 B | 87.20% |

RGBA 추정은 이미지 너비×높이×4의 합계이며 전체 브라우저 메모리나 GPU 실제 사용량을 측정한 값은 아니다. 플레이에 등장한 캐릭터만 지연 로딩하는 기존 방식은 유지한다.

## 최적화 방식과 화질

- 원본 PNG를 수정하지 않고 알파 경계를 측정해 포즈를 촘촘히 배치했다. 75% 해상도와 WebP quality 90을 사용하며 포즈 사이 2px 투명 여백으로 보간 번짐을 막는다.
- 모든 102포즈를 파란 배경에 합성해 기존 WebP와 SSIM 비교했다. 보드용 120px에서 평균 0.998162/최저 0.995783, 컷인용 335px에서 평균 0.986188/최저 0.970246이다. 실제 보드와 컷인 캡처도 검수했다.
- 글꼴은 WOFF2로 압축했으며 2,733개 유니코드 문자·2,734개 글리프와 전체 가로 메트릭이 원본과 동일한지 검사했다. 글자 서브셋을 제거하지 않았다. 원본 TTF는 저장소에 보존하고 배포에서는 제외한다.
- 레이아웃이 바뀐 아틀라스 URL에는 체크섬 버전을 붙인다. 이전 이미지 캐시와 새로운 프레임 좌표가 섞여 다른 캐릭터 조각이 표시되는 문제를 방지한다.
- 전투 투영 패치 25개와 축, 전신 최대 경계, 글꼴 변환 결과를 재사용한다. 크기가 바뀌면 좌표·폰트 캐시를 다시 만든다.
- 동일한 밀집 보드에서 headless Chromium의 warm CPU draw 제출 시간을 기록했다. 소폭 차이는 환경 잡음과 구분할 수 없어 실제 기기 FPS 향상으로 주장하지 않는다.

## 재현

`python scripts/export-matching-battle-sprites.py`로 전신을 내보낸다(Pillow, ImageMagick). `python scripts/optimize-battle-ui-assets.py`로 글꼴·아이콘을 인코딩한다(fontTools, Brotli, ImageMagick). 원본 아이콘은 `designs/battle-optimization-20261110/`에 보존했다. 필요 의존성 설치는 환경의 패키지 정책을 따른다.

`UI_PERF_OUT=... node scripts/benchmark-battle.cjs`로 렌더 제출 시간과 이미지 예산을 측정한다. `python scripts/compare-battle-atlas-quality.py <이전 character-motion 디렉터리>`로 화질을 비교한다. 이전 애셋은 기준 커밋에서 추출할 수 있다.

Node 81개, 배포 패키지 Chromium 20개. 새 용량·메모리 예산, 프레임 사이 여백, 캐시 버전, 360px 경계의 연속성을 검사한다. 전투·아이템 선택·취소·일시정지·저장/이어하기·보상·전신·기존 적군 모션도 검사한다.
