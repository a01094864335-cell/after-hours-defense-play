## 그대로 유지한 아트 기준

- 고비: 연두색 피부, 밤색 헝클어진 머리, 자주색 조끼/타이, 클립보드. 옷이나 조명으로 생기는 채도 차이는 별개 인물로 취급하지 않는다.
- 찌릿: 기존 스토리의 주황색 점박이 도마뱀, 노란 번개 안전모, 보라 작업복과 꼬리. 인간/금발 캐릭터로 바꾸지 않는다.
- 실비: 보라 거미, 둥근 머리, 금테 안경, 추가 눈, 붉은 머릿수건. 흰머리 인간형은 사용하지 않는다.
- 토르크: 둥근 연두 얼굴, 짧은 검푸른 곱슬머리, 굵은 눈썹, 넓은 웃음. 작업복/고글은 상황별 소품으로 허용한다.
- 기존 스토리는 배경과 따뜻한 조명이 풍부한 회화적 치비 스타일이다. 작은 UI 초상화의 평면적인 선을 배경 전체에 강제로 적용하지 않는다.
- 대표 외형을 읽을 수 있는 차이는 고치되, 의상·표정·명암·촬영각 차이는 자연스러운 연출로 유지한다.
- 캐릭터 얼굴 주변의 흰 스티커 외곽선과 은은한 그림자는 의도된 메인 스타일이다. 무조건 잘라내거나 투명화하지 않는다.

## 제한과 후속 제작 기준

기본 이야기 화면은 대사를 동시에 보여주므로 짧은 기기에서 원화 일부가 크롭될 수 있다. 전체 그림과 모든 소품이 필요하면 ‘그림 전체’를 사용한다. 이미지 자체를 훼손하는 강제 가로 늘이기는 하지 않는다.

텍스트는 HTML/CSS로 관리한다. 새 버튼은 영문 문서 언어에서 `Full art` / `Read story`를 사용한다. 이번 검증의 영문 문장은 출시 번역 확정본이 아니다. 옛 참고 시안에 이미지로 구워진 한글은 과거 자료로 남기며, 신규 런타임 제작의 기준으로 재사용하지 않는다.

생성 편집은 원본 픽셀 보존 작업이 아니어서 배경의 작은 장식·주변 인물의 세부 선은 일부 달라질 수 있다. 편집 전·후를 리뷰 페이지에서 모두 비교할 수 있도록 했다.
