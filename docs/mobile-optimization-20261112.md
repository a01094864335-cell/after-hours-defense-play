# 모바일 로딩 및 대기 전력 최적화

기준 main은 `fe861c7`입니다. 기존 화면 구성과 캐릭터 그림, 전투 속도·보상·저장 형식을 유지하며 불필요한 다운로드와 반복 작업을 줄였습니다.

## 변경

- 이전 표현 계층의 메인·상점·훈련·종료 그림은 실제 표시될 때 요청합니다. 현재 화면에 필요하지 않은 그림은 먼저 내려받지 않습니다. 상점 대표 그림과 훈련 목록도 해당 영역이 보일 때 불러옵니다.
- 메인 배경·로고·고비·공통 종이·상점 그림 5개를 WebP로 재압축했습니다. 로고와 종이는 실제 표시 크기에 맞춰 원본 해상도도 줄였습니다. 전신 애니메이션·윤곽선 마스크·스토리 원화는 변경하지 않았습니다.
- BGM 3곡을 동일한 원본에서 64kbps MP3로 제공해 다운로드를 줄였습니다. 기존 PCM 원본과 사용자 볼륨·음소거 설정은 유지합니다.
- 모바일 절전 모드의 전투 준비 화면은 도착 이펙트가 끝나면 프레임 예약을 멈춥니다. 소환·조작·화면 변화가 발생하면 깨어나며, 실제 전투는 기존 30fps 렌더링과 60Hz 시뮬레이션을 유지합니다. 60fps 사용자 선택도 유지합니다.
- 절전 모드의 Shadow DOM 안 메인 로고 애니메이션을 중지합니다. 숨겨진 탭의 CSS 애니메이션도 멈춥니다.
- 일반 공격과 경비원 스킬의 선두 적 선택에서 매번 생성하던 필터 배열·정렬을 단일 탐색으로 바꿨습니다. 동률이면 기존의 첫 대상을 유지하고 처치 직후 다음 대상으로 전환합니다.

## 측정

Chromium 390×844, 격리된 콜드 캐시, 공식 Pages 빌드를 로컬 서버에 올려 비교했습니다. 공개 CDN의 압축된 전송량이나 실제 휴대폰 온도를 측정한 수치는 아닙니다. 각 작업량 구간은 초기 상태가 안정된 뒤 5초입니다.

| 항목 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 초기 리소스 본문 합계 | 약 5.06MB | 약 3.64MB |
| 초기 이미지 본문 합계 | 약 3.49MB | 약 2.07MB |
| 초기 요청 수 | 191 | 181 |
| 절전 준비 화면 렌더링 | 150회 / 5초 | 0회 / 5초 |
| 절전 준비 화면 업데이트 | 300회 / 5초 | 0회 / 5초 |
| BGM 3곡 파일 합계 | 4,580,872bytes | 833,119bytes |

초기 본문은 약 28%, 초기 이미지는 약 41%, BGM은 약 82% 줄었습니다. 측정 시점의 표시·지연 로딩 순서에 따라 개별 요청 수는 달라질 수 있습니다. 실제 전투의 프레임 제한이나 게임 배속을 낮춘 결과가 아닙니다. 실제 발열 개선 폭은 기기·브라우저·플레이 시간에 따라 달라지므로 온도 하락 수치로 환산하지 않습니다.

## 검증 및 근거

- 런타임 전체 3,313건 통과. 선두 대상의 동률·사망 후 재탐색, 오디오의 지연 시작·음소거·장면 전환과 MP3 파일 검증을 포함합니다.
- 성능 브라우저 검사 9건과 숨겨진 이미지 로딩 검사 1건 통과. 준비 화면에서 멈춘 뒤 실제 소환 버튼을 5번 눌러 전투가 시작되는 흐름을 확인했습니다.
- 초기 이미지 예산을 4.2MB에서 2.5MB로 강화하고, 숨겨진 구형 그림이 초기 요청에 없는지 및 상점 진입 후 실제 대표 그림이 표시되는지 검사합니다.
- 기존 전체 기능 반복과 WebKit 모달 검사는 배포 워크플로에서 수행합니다. 실제 모바일 Safari의 발열 측정은 별도로 필요합니다.
- [전후 측정·화면·원본 로그](../qa/mobile-optimization-20261112/)와 [이미지 변경 내역](../qa/mobile-optimization-20261112/image-changes.json)을 보관했습니다.

전체 기능 검사의 첫 반복에서는 114개 중 113개 통과, 상점 그림의 즉시 로드를 가정한 1개 검사가 실패했습니다. 그림을 실제 표시할 때 내려받도록 바꾼 동작에 맞춰 로드 완료를 기다린 뒤 기존 이미지·영문 제목·실제 구매 검증을 유지했습니다. 수정 후 텍스트 그리드 5개 검사가 통과했으며 최초 실패와 재검증 로그를 보존했습니다.
