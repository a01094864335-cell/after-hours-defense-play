# 원본 시안 좌표로 구성한 플레이 화면

[시안·이전 화면·실제 반영 비교와 겹쳐보기](../assets/battle-exact/comparison.html) · [5크기 검수 자료](../qa/battle-exact-20261110/index.html) · [검사 요약](../qa/battle-exact-20261110/summary.json).

## 기준과 결과

승인 시안 `designs/battle-comic-20261110/approved-concept.png`의 948×1659 원본을 구성 기준으로 삼았다. 기존의 흐름형 CSS 패널 배치를 조정하는 방식에서, 원본 시안의 위치·크기·그림을 보존한 글자 없는 전용 아트와 실제 DOM/전투 Canvas를 겹치는 방식으로 변경했다.

성곽·달·깃발·횃불·둥근 이동로·5×3 바닥·입구/성문, 종이 스킬 배너, 금색 소환 버튼, 남색 SP 영역, 크림색 HUD/아이템 버튼 표면을 같은 구성으로 제작했다. 동적인 캐릭터·텍스트·숫자·체력·등급·재사용 대기·아이템 아이콘은 배경에 포함하지 않았다.

HUD·공격 상태 바·전투 영역·선택 스킬·소환/SP/장비·하단 아이템의 6영역을 원본 비율 좌표에 고정한다. 글자·아이콘과 실제 버튼은 DOM이다. 전신 캐릭터, 이름 없는 하단 아이콘, 기존 적군은 앞서 요청한 표현을 유지한다. 예시 숫자·배치·공격 효과는 실제 플레이 상태를 표시한다.

## 구성 계약

`assets/battle-exact/composition.json`에 원본 크기, 6영역의 정규화된 사각형, 실제 아트 타일 경계와 월드 투영 축을 기록했다. 최종 위치는 `battle-exact.css`가 담당한다. 새 레이아웃을 바꿀 때 이 파일과 계약/검사를 함께 갱신하고, 이전 흐름형 보드나 단색 CSS 컨테이너로 돌아가지 않는다.

원본 비율에서 시안과 같은 배치가 되고, 다른 세로 화면에서도 영역의 순서와 비율을 유지한다. HUD는 별도 원본 비율 스트립으로 덮어 긴 화면에서 원형 버튼이 찌그러지지 않게 했다. 짧은 화면에서는 글꼴 크기를 높이/폭 중 작은 기준으로 제한한다. 하단 버튼의 44px 클릭 영역과 실제 아이콘·수량 위치를 분리해 그림을 밀어내지 않는다.

## 실시간 렌더링과 기능

배경은 `arena-ui.webp` 한 장이며 `hud.webp`는 같은 원본에서 추출한 스트립이다. 문자나 상호작용 아이콘이 들어 있지 않아 영문 표시를 위해 그림을 다시 만들 필요가 없다. 뒤로가기·SP 번개·장비 아이콘은 벡터로 고정하고 문구·수치는 DOM에서 갱신한다.

기존 600×600 전투 좌표와 `cells`·`path`, 공격 범위·확률·가격·스킬·저장 형식은 유지한다. 실제 원화의 5열 경계에 맞춰 투영과 역변환을 갱신했고 선택 표시도 그림의 타일 경계를 따라 그린다. 입력 Canvas와 기존 버튼 노드/핸들러를 유지했다. 적군·전신 102포즈·공격/피격/합성/지원/마왕 효과와 컷인도 기존 렌더링 경로를 사용한다.

진행 표시의 5개 점, 남은 적/다음 공격 시간, SP·체력·속도·아이템 수량은 실제 값이다. 안내 문구는 준비 단계에 표시하고 일반 전투 중에는 잠깐 나타난 뒤 사라지며 상태 바 클릭으로 전체 안내를 다시 볼 수 있다. 아이템 선택 안내·군단장 경고·튜토리얼·일시정지·전투 체험 기능을 유지한다.

## 보강한 애셋과 재수출

- `designs/battle-exact-20261110/wordless-plate-master.png`: 승인 시안에서 글자·캐릭터·동적 요소를 비운 원본. 새 배경 레이아웃을 독립적으로 재해석하지 않았다.
- `designs/battle-exact-20261110/item-icons-master.png`: 서류/카드 더미, 합성 쌍 얼굴, 초승달 망토의 3아이콘 원본.
- `python scripts/export-exact-battle-assets.py`: ImageMagick와 Pillow를 사용한 기계적 인코딩/셀 추출. 배경은 948×1659 WebP quality 91, HUD는 상단 100px 추출, 아이콘은 알파 경계 측정 후 256px로 내보낸다. 원본 그림을 스크립트로 다시 그리지 않는다.
- 원본 PNG/QA는 배포에서 제외한다. 압축된 전신 아틀라스와 체크섬 캐시 방식은 유지한다. 한글 전체 글리프를 보존한 WOFF2도 유지한다.

## 검증

Node 81개·배포 패키지 Chromium 22개. 추가한 검사는 5개 화면의 실제 DOM을 구성 계약과 비교하고 전체 뷰포트 크기를 확인한다. 실측한 30영역의 최대 사각형 오차는 약 0.015px다. 이는 화면 영역 위치·크기의 오차이며 그림·글자·게임 상태의 픽셀 차이를 의미하지 않는다.

320×568·390×640·390×684·390×844·430×932의 전투·아이템 선택·일시정지에서 스크립트 오류·누락 자산·DOM 기하 문제 0건이다. 17명×6포즈×4크기 = 408조합에서 캐릭터/상태 글자 충돌과 글자·그리드 문제 0건. 큰 화면에서 누르는 순간 헤더 버튼이 이동해 클릭이 취소되던 문제와 짧은 화면의 스킬명/등급 간격도 검사·수정했다.

`node scripts/audit-exact-composition.cjs`로 좌표 오차를, `node scripts/capture-comic-battle.cjs`로 상태별 화면을 다시 기록한다. 실제 게임 코드를 구동한 결정된 테스트 상태를 캡처하며, 별도의 기능 검사는 실제 입력·전투·저장/이어하기를 수행한다. 공개 주소 직접 재촬영은 실행 프록시 제약이 있어 동일한 배포 패키지와 GitHub 게시 결과로 확인한다.
