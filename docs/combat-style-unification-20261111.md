# 마왕·적군·지원 영웅 그림체 통일

기준은 이미 승인된 보드 직원 17종의 `main-comic` 그림체다. 굵은 남색 외곽선, 좁은 흰 스티커 테두리, 명확한 셀 채색, 큰 머리와 작은 전신 비율을 공통으로 사용한다. 캐릭터별 얼굴·종족·색상·복장·무기와 게임 기능을 유지하면서 전투 애셋을 새로 그렸다.

## 교체 목록

| 범위 | 대상 | 반영 |
|---|---|---|
| 마왕 1종 | 마왕 | 전신 6포즈, 등장·잔광 연출, 동일한 대기 fallback, 튜토리얼·대화용 얼굴 |
| 일반 적 5종 | 견습 용사·정찰 도적·방패 기사·치유 사제·번개 마법사 | 픽셀풍을 보드 직원과 같은 코믹풍으로 교체, 이동·공격·피격 6포즈 |
| 군단장 7종 | 레온·아이기스·루비·루멘·네베·미라·크로노 | 공통 선·채색·두신으로 통일, 장비와 실루엣 유지, 각 6포즈 |
| 지원 영웅 7종 | 결계 계약직·야간 회계사·비상 대응반·칙칙·반창·코코·큐 | 전신 6포즈와 얼굴 배지 모두 새 그림체로 통일, 메뉴/편성/훈련/채용/전투에서 동일 얼굴 사용 |

총 전신 **20종 × 6포즈 = 120포즈**, 새 얼굴 **8종**이다. 기존 직원 17종의 그림은 변경하지 않았다. 지원 영웅은 앞서 승인한 자동 지원 얼굴 배지 UI를 유지하며, 전신을 쓰는 갤러리·모션 경로도 새 애셋으로 연결한다.

## 정체성과 형태

- 마왕: 보라색 피부, 흰 머리, 금장 검은 뿔, 금빛 눈, 정장과 붉은 망토, 꼬리, 커피잔·서류가방 유지.
- 회계사와 큐: 각각 부엉이와 까마귀의 부리·날개·발을 유지한다. 큐의 금색 안경은 얼굴 배지와 전신 모두에 있다.
- 코코: 사람형 몸체 대신 네 발 고양이를 유지한다.
- 칙칙: 유령 꼬리와 기관차·랜턴을 유지한다. 다리나 신발을 추가하지 않는다.
- 반창: 분홍 아홀로틀의 외부 아가미와 꼬리를 유지한다.
- 군단장: 머리색, 모자/투구, 방패·창·종·거울·시계 등 주요 식별 장비를 유지한다.

이야기 장면 전체를 다시 그리지는 않는다. 전투 배우와 별도로 구성된 기존 내러티브 장면은 유지하며, 대화의 작은 캐릭터 얼굴만 동일한 기준으로 연결했다.

## 연결과 표시

`assets/combat-comic/manifest.js`를 `motion.js` 및 게임 초기화보다 먼저 로드해, 이전 적/군단장/지원/마왕 등록을 같은 ID로 교체한다. 모션, 피격/처치 이미지, 대기 fallback이 모두 같은 새 원화를 사용한다. 지원 얼굴 경로는 기존 공통 경로를 유지하고 해시 쿼리로 캐시를 갱신한다.

적군은 포즈마다 무기 너비가 달라져도 전체 크기가 흔들리지 않도록 6포즈 최대 너비를 공통 제한으로 사용한다. 마왕 등장·잔광 연출 동안에는 지원 배지만 잠시 감춰 마왕 등장 문구를 가리지 않게 한다. 실제 지원 효과는 그대로 동작한다. 위치·경로·체력·속도·공격 판정·보상·저장 형식은 변경하지 않는다. 앞서 배포한 5웨이브 보상 개편도 유지한다.

## 용량과 재현

원화는 `designs/combat-style-20261111/`, 런타임은 `assets/combat-comic/`에 분리했다. 재현은 `python scripts/export-combat-comic.py`로 가능하다. 투명 여백을 측정해 잘라내고 가장자리 간격을 둔 WebP 아틀라스로 패킹한다. 전투용 크기로 줄여 원화 20장을 그대로 디코딩하지 않는다. 구체적인 이전/이후 전송·디코딩 크기는 `qa/combat-style-20261111/asset-measurements.json`에 기록한다.

## 검증

- 20종 그룹·6포즈·범위·기준점·해시·fallback 일치 검사.
- 실제 Chromium Canvas에서 120포즈 렌더, 빈 그림과 화면 가장자리 잘림 검사.
- 실제 게임 320×568·390×844에서 일반 적·군단장·마왕 등장/잔광·지원 7종 캡처.
- 얼굴 배지·선택 스킬·기존 직원 17종·좌표/전투 상태 불변 회귀 검사.
- 전체 런타임 검사, 공식 배포 패키지 검사, GitHub Actions 배포 전 전체 모달 및 반복 기능 검사.

대표 캡처와 전후 비교는 `qa/combat-style-20261111/`에 저장한다. 공개 GitHub Pages 직접 캡처는 환경 프록시 제한이 있으므로 로컬 공식 배포 패키지에서 확인하고, 공개 반영 여부는 해당 메인 커밋의 Pages 배포 작업 성공으로 확인한다.
