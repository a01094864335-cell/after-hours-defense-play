# UI 텍스트 정리

2026-11-06. 기본 화면은 이름·역할·상태·가격·다음 행동에 집중한다.

- 로비: 로고 아래 슬로건과 상단 중복 변주 표기를 제거했다. 편성은 인원수만 표시하며 공격/지원 인원은 접근성 이름에 남긴다.
- 전투: 지원 영웅 설명 카드를 근무 안내로 옮겼다. 보드의 영웅은 유지한다. 소환·스킬 결과 문구를 줄이고 반복 초상화를 제거했다. 알림은 한 줄로 표시하고 터치/키보드로 전체 문구를 볼 수 있다.
- 직원 목록: 사번·직업·대사와 반복 안내를 제거하고 이름·전투 역할·편성 상태를 남겼다. 상세 기록에서는 능력과 이야기를 볼 수 있다.
- 훈련소: 현재 레벨과 다음 효과만 먼저 보여준다. 레벨과 중복되는 진행 바를 없앴다. 영웅별 효과와 성장 세부 수치는 펼쳐서 확인한다.
- 상점: 반복 구매 설명과 도감 이동 버튼의 긴 문구를 줄였다. 기본 화면에는 일반 90% / 지원 10%를 표시하며 확률·보장·중복 포인트 규칙은 펼쳐서 확인한다.
- 기록·이야기·결과: 반복 안내를 줄이고, 당직 분석은 접어두었다. 코인 보상은 큰 보상 카드에 표시하고 아래 통계의 중복 코인 행은 제거했다.

가격·잔액·능력 수치, 합성 실패·저장 오류·당직 포기 경고, 튜토리얼의 실습 지시와 이야기 본문은 보존한다. 게임 규칙과 저장 형식은 바꾸지 않았다.

## 기본 펼침 텍스트 비교

같은 Chromium 390×844와 GM 고용 완료 fixture, 메인 패널 또는 열린 다이얼로그의 렌더링된 텍스트 노드(공백 제외)를 비교했다. 접힌 내용은 제외하고 스크롤 아래 내용은 포함한다. CSS 생성 라벨과 캔버스 글자는 포함하지 않으므로 실제 화면의 모든 글자 수를 뜻하지 않는다. 단순 문구 삭제와 설명 접기를 함께 측정한 값이다.

## 검증

- 런타임 54개 및 배포 빌드 브라우저 검사 8개 통과.
- 320×568, 390×844, 430×932 전체 화면·스크롤 133개 레이아웃 검사 오류 없음.
- 훈련 카드 최종 간격 조정 후 세 크기에서 기본/펼침 상태 추가 검사 오류 없음.
- 여섯 모바일 크기에서 15칸 터치 선택, 드래그 합성, 전투 시작/일시정지/재개 통과.
- 훈련 효과 키보드 펼침, 구매 규칙 펼침, 지원 상세와 긴 전투 알림 확인, 결과 분석 펼침 검사 통과.
- 대표 전후 캡처와 320px 화면, 펼친 설명을 직접 확인했다.

증거는 `qa/less-ui-text/`에 보관한다. `scripts/check-text-density.cjs`는 이전 리비전 파일을 로컬 요청에 적용해 같은 브라우저에서 비교하며, 구매/훈련 데이터는 로컬 fixture만 사용한다. 로컬 서버를 8840 포트에서 실행한 뒤 `node scripts/check-text-density.cjs`로 재현할 수 있다.
