# GNB·닫기·뒤로가기 공통화

2026-11-10. 메인·도감·상점·훈련소의 공통 조작부를 `shared-chrome.js`와 `shared-chrome.css`에서 관리한다.

## 변경

기존 GNB는 글자·아이콘·버튼 전체가 포함된 서로 다른 비율의 비트맵을 57~67px 높이로 늘이거나 압축했다. 이제 기존 버튼과 핸들러를 유지하면서 배경 이미지를 제거하고 공통 DOM GNB를 사용한다. 도크는 78px, 버튼은 66px, 아이콘은 비율을 유지하는 30px 정사각형이다. 3개 메뉴의 간격·글꼴·현재 메뉴 표현과 안전 영역 처리를 통일했다. 훈련소에서는 상위 메뉴인 당직실을 표시한다.

닫기·뒤로가기는 크림색 원형 44px 버튼과 24px 아이콘으로 통일했다. 도감·상점·훈련소의 전용 헤더와 설정·이야기·기록·백업 등 일반 팝업에 적용한다. 완료·닫기 버튼의 기존 접근 가능한 이름과 실제 이벤트 핸들러는 유지한다. 확인·구매·취소 등 기능이 다른 액션은 기존 버튼으로 남긴다. 전투 HUD는 승인 시안 배치를 유지한다.

선택한 공통 애셋은 `assets/open-scene/icons/`의 book·home·shop·close·back SVG다. 늘여 그린 비트맵 대신 같은 아이콘 계열을 모든 화면에서 재사용한다. 문구는 DOM으로 분리되어 영문판에서 바꿀 수 있다.

## 구조

메인은 light DOM, 도감·상점·훈련소는 각각 Shadow DOM이므로 공통 CSS를 각 루트에 동일하게 로드한다. 동적으로 생성되는 팝업도 관찰하며, 이미 처리한 요소는 다시 만들지 않는다. 게임의 구매·훈련·편성·저장 로직은 변경하지 않는다.

## 확인

`tests/test_shared_chrome.py`는 320×568·390×684·390×844·430×932에서 메인·도감·상점·훈련소 16개 화면을 확인한다. GNB 터치 영역·아이콘 종횡비·현재 메뉴 표시·공통 닫기 크기, 실제 도감→상점→메인 이동과 설정 닫기를 검사한다. 캡처는 `qa/shared-chrome-20261110/`에 보관한다. 전체 배포 브라우저 검사에도 포함했다.

검증 결과: Node 81개, 배포 패키지 Chromium 23개 통과. 공통 조작부 전용 검사와 16개 캡처를 포함한다.

공개 주소 직접 캡처는 실행 환경의 프록시 제약이 있어 로컬 배포 패키지에서 수행하고 GitHub Actions의 배포 결과를 별도로 확인한다.
