## 범위와 증거

- 배포 패키지 이미지 **884개**: 래스터는 실제 디코딩·크기·해시, SVG는 XML 파싱. 0오류. **884개를 모두 원화 수준으로 수작업 감수했다는 뜻은 아니다.** 과거 시안/호환 그림도 패키지에 포함된다.
- 시각 대조: 스토리 **236장면**, 직원 **17종×6포즈**와 기준 초상화, 마왕·적·보스·지원 **20종×6포즈**. 파생 컨택트 시트는 검토용 썸네일이며 원본 수정이 아니다.
- 실제 주요 화면: **21상태×3크기(320×568 / 390×844 / 430×932)×2언어 = 126장**. 지원 영웅 **7종×2언어 = 14장** 추가. 화면은 게임의 원래 렌더러와 격리된 테스트 저장 상태로 생성한다.
- 실제 스토리 재생: **236상태×2언어 = 472상태**, 320×568에서 이미지 디코딩/그림 크기/대사창 위치 조사. 전체 화면 배경은 의도적으로 대사창 뒤까지 이어지므로 배경과 대사창의 사각형 겹침을 오류로 판정하지 않는다. 원화의 모든 손가락·미세 선을 무결하다고 보장하는 검사도 아니다.
- 영문 모드의 스토리/소개 초벌은 유지된다. 일부 일반 UI는 아직 한국어이며 설정의 기존 안내와 같다. 이번 작업은 영문 전체 현지화 완료를 의미하지 않는다.
- 공개 호스트는 실행 환경에서 접근 제한이 있어 캡처는 **정식 Pages 패키지의 로컬 실행** 기준이다. 공개 배포 성공은 GitHub Actions로 별도 확인한다.
