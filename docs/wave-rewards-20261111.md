# 5웨이브 보상: 운영·성장·상황 3개 선택지

## 반영 범위

지원 영웅 얼굴 배지·미선택 스킬 안내 UI는 PR #43으로 메인에 반영됐다. 이번 변경은 승인한 단계별 보상안을 실제 전투 로직, 저장/복구, 보상 화면에 적용한다. 기존 밝은 파랑·크림·노랑 티켓 디자인과 캐릭터 얼굴 애셋을 재사용한다. 새 이미지 다운로드는 추가하지 않는다.

## 단계별 기본 제시안

세로로 운영 / 성장 / 상황 순서의 카드 **3개만** 제시하고 1개를 선택하면 다음 웨이브를 시작한다. 각 카드는 대상과 효과가 확정된 단일 보상이다.

| 완료 웨이브 | 운영 | 성장 | 상황: 생명 부족 시 / 최대 시 |
|---|---|---|---|
| 5 | 기본 소환 2회분 SP | 합성 성공 보장 +1회 | 생명 +1 / 장비 +1레벨 |
| 10 | 기본 소환 3회분 SP | 장비 +1레벨 | 생명 +1 / 당직 전략 1종 |
| 15 | 기본 소환 4회분 SP | 출전 덱 ★3 직원 1명 | 생명 +1 / 합성 성공 보장 +2회 |
| 20 | 기본 소환 5회분 SP | 종류 유지 합성 1회 | 생명 +1 / 장비 +1레벨 |
| 25 | 기본 소환 5회분 SP | 출전 덱 ★4 직원 1명 | 생명 +1 / 미선택 당직 전략 1종 |
| 30 | 기본 소환 5회분 SP | 장비 +2레벨 | 생명 +1 / 출전 덱 ★5 직원 1명 |
| 35 이후, 5의 배수 | 기본 소환 5회분 SP | 장비 → ★5 직원 → 종류 유지 순환 | 생명 +1 / 다음 5웨이브 화력 지원 |

- SP는 현재 소환 기본 가격부터 매회 +10 가격 상승을 포함해 합산한다. 예: 기본 가격 500이면 5회분은 500+510+520+530+540=2,600 SP. 오늘의 소환 할증은 포함하고, 일회용 반값 쿠폰·용병의 무료 소환은 제외한다. 이전의 고정 SP 하한은 사용하지 않는다.
- 합성 성공 보장은 **남은 횟수에 추가**, 최대 3회다. 2회 보유 상태에서 +2회 보상을 고르면 `2 → 3회`라고 표시한다. 3회 보유 중이면 해당 보상 대신 다른 유효 보상을 제시한다.
- 종류 유지는 다음 유효 합성을 100% 성공시키며 도착 직원의 종류를 유지한다. 최대 1회 보유하며 일반 성공 보장과 별도다. 둘이 함께 있으면 종류 유지만 소비한다.
- 생명은 한 번에 1만 회복하며 최대 3이다.
- 장비는 출전 덱 중 강화 가능한 직군을 선택한다. 현재 보드에 배치된 직군을 우선하고 장비 레벨이 낮은 순, 동일하면 직군 순으로 고른다. `경비원 전체 · Lv.1 → 2`처럼 대상과 최종 효과를 카드에 직접 보여준다.
- 직원은 출전 덱의 현재 최고 등급이 낮은 직원부터 선택한다. 빈 칸이 필요하며 첫 빈 칸에 배치한다. 이번 전투에만 지급하고 영구 채용·도감 해금·아이템 저장은 하지 않는다.
- 당직 전략은 한 전투에 1종만 획득한다. 서기가 덱에 있거나 회계 용병을 사용하면 정산 특근(수입 +25%), 그 외에는 연쇄 잔광(0.8초마다 추가 대상 피해 25%)을 제시한다. 기존 비상 방벽 효과와 이전 저장 데이터도 유지한다.

## 받을 수 없는 보상의 대체

최대 생명·만석 보드·장비 Lv.5·이미 보유한 전략/합성 보호는 비활성 카드를 남기는 대신 다른 유효 카드로 교체한다. 같은 보상 종류를 두 칸에 중복 제시하지 않는다. 일반 대체 순서는 장비 → 합성 보장 → 직원 → 전략 → 종류 유지 → 화력 지원 → 군단장 추격 → 진군 지연이다. 각 칸의 기본안이 먼저 적용되므로, 이 순서는 기본안을 받을 수 없을 때만 사용한다.

보드 전원이 ★7이고 장비도 모두 Lv.5인 상황에서는 SP도 제시하지 않는다. 전원이 ★7이면 합성 보호도 제외한다. 최종적으로 선택할 수 있는 전투 지원은 다음과 같다.

| 임시 지원 | 효과 | 유효 기간 |
|---|---|---|
| 화력 지원 | 피해 +10% | 선택 직후 다음 웨이브부터 5개 웨이브 |
| 군단장 추격 | 실제 군단장 피해 +20%, 분신 제외 | 동일 |
| 진군 지연 | 모든 적 이동 속도 -10% | 동일 |

예: 35웨이브 보상에서 선택하면 36~40웨이브에 적용되고 41부터 적용되지 않는다. 임시 지원은 1종만 유지하며 중첩되지 않는다. 피해 공유에는 같은 보너스를 재차 곱하지 않는다. 연쇄 잔광의 추가 타격에도 해당 대상의 피해 보너스를 적용한다. 진군 지연은 매 프레임 실제 이동량에 적용해 저장/복구 또는 새 적 생성으로 속도가 누적 감소하지 않는다.

## 저장·재배치·중복 수령

- `rewardBundle`에 완료 웨이브, 카드 순서, 보상 종류, 대상, 수량을 저장한다. 저장한 보상을 다시 열거나 새로고침하거나 재배치해도 유효한 카드를 새로 추첨하지 않는다. 대상 선정 자체도 결정적이다.
- 보상 창을 닫고 재배치한 뒤 돌아와도 같은 카드를 보여준다. 만약 대상이 최대치가 되는 등 상태가 실제로 바뀌어 수령할 수 없어진 경우에는 그 카드만 유효한 보상으로 대체한다.
- 선택 시 진행 중·일시정지·보상 대기·저장 쓰기 소유권·대상 유효성을 확인한다. 수령 뒤 보상 대기를 해제하고 다음 웨이브와 함께 저장하므로 중복 클릭으로 보상을 두 번 받지 않는다.
- 저장 데이터에 새 보상 필드가 없으면 기존 전투를 그대로 복원한다. 카드 수·중복 종류·덱 밖 대상·잘못된 수량·잘못된 임시 지원 기간은 복원 전 검증한다.
- **전열 정비**는 보상을 소비하지 않는 별도 버튼이다. **퇴근 정산**은 15·30·45… 완료 시 별도 버튼으로 유지한다. 코인 정산 공식과 중복 지급 방지 장부는 유지한다.
- 신입 연수는 고급 전략·종류 유지 선택을 제외한다. 10웨이브 수료 동작은 유지한다.

## 화면 및 영문 대응

장비/직원 선택 뒤 5개 대상을 다시 늘어놓는 화면은 제거했다. 티켓의 실제 DOM 텍스트를 운영 구분·보상명·큰 효과·대상/기간 네 줄로 나눴다. 텍스트를 애셋에 굽지 않는다. `html lang=en`일 때 보상 문구·제목·정비/정산 버튼은 영문으로 렌더링한다. 직원 이름과 게임 전체의 영어 현지화는 별도 작업이며 이번 변경을 전체 영문판 출시로 보지 않는다.

320×568, 390×844에서 5·10·15·20·25·30·35웨이브, 한글/영문 28개 상태를 캡처하고 검사했다. 작은 화면에서도 세 카드가 모두 보이도록 얼굴·타이포·여백을 조절하고, 정비/정산 버튼은 나란히 배치했다. 상세 규칙은 카드와 유틸리티 아래 접기 영역으로 옮겼다. 긴 규칙과 보유 효과는 스크롤로 확인할 수 있다.
