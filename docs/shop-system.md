# 통합 채용팩과 지원 영웅 편성 정책

2026-10-23 적용. 기존 지원 용병 직접 구매 정책을 대체합니다.

- 상점은 채용팩과 개별 아이템 두 탭으로 구성합니다. 기존 코인 가격을 유지합니다.
- 채용팩 1개에서 영웅 1명: 일반 직원 총 90%(12종 각 7.5%), 지원 영웅 총 10%(3종 각 10/3%). 보유 여부와 관계없이 동일 확률입니다.
- 신규 일반 직원은 직원 목록에, 신규 지원 영웅은 기존 영구 고용 목록에 저장합니다. 자동 편성하지 않습니다.
- 중복은 종류에 관계없이 채용 포인트 1을 지급합니다. 3포인트 지정 채용은 기존 미채용 일반 직원에 적용합니다.
- 일반 12명과 지원 3명 모두 보유하면 채용팩 구매를 막습니다.
- 지원 영웅은 직원 도감 → 지원 영웅 → 인사기록에서 1명 선택하거나 해제합니다. 일반 직원의 5인 근무 명단 슬롯을 사용하지 않습니다. 로비 지원 슬롯도 해당 도감으로 연결합니다.
- 전투 진행 중 채용과 지원 교체를 막고 기존 전투 시작 시 지원 스냅샷을 유지합니다. 개별 아이템 구매는 기존 정책을 따릅니다.
- 코인 차감과 획득은 하나의 저장 변경으로 처리합니다. 저장 실패 시 둘 다 적용하지 않습니다. 기존 고용·편성·훈련 기록과 GM 모드 저장 분리를 유지합니다.
