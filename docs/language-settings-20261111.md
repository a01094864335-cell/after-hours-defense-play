# 메인 설정의 한국어 / English 선택

메인 우측 상단 설정에서 **언어 / Language → 한국어 또는 English**를 선택한다. 현재 선택은 파란 버튼과 `aria-pressed`로 표시하고, 새로고침 없이 적용한다. 두 버튼의 이름은 어느 언어에서도 그대로 유지해 한국어로 쉽게 돌아올 수 있다.

## 저장과 전투 보존

- 기본 언어는 한국어다. 지원 값은 `ko`, `en`만 허용한다.
- `GameStorage`의 별도 키 `after-hours-language-v1`에 보관하고, 게임 UI 초기화 전에 `html lang`에 복원한다.
- 언어는 현재 브라우저의 환경설정이다. 코인·채용·편성·전투 스냅샷·백업 데이터 형식은 바꾸지 않으며 전투를 다시 시작하거나 재로딩하지 않는다.
- 저장이 실패하면 기존 언어를 유지하고 설정에서 다시 시도할 수 있는 오류를 표시한다.
- 같은 브라우저의 다른 탭에서 정상 모드 언어가 바뀌면 반영한다. GM/새 기기 테스트 모드는 기존 GameStorage 격리를 유지한다.

## 현재 번역 범위

이번 변경은 **언어 선택 기능과 기본 UI의 영문 전환**이다. 게임 전체의 영문 출시가 완료됐다는 의미는 아니다.

- 메인: 시작/이어하기, 메뉴/바로가기, 오늘의 당직, 모드·변주 이름, 기본 안내, 공통 GNB.
- 설정: 제목·설정 그룹·배경음/효과음·화면/절전/스킬 연출·도구·백업·초기화·닫기/확인.
- 공통 페이지 제목/내비게이션/닫기 접근성 이름. 기존 `html lang` 기반 지원 상태·스킬 미선택 안내·보상 카드는 언어 선택에 함께 반응한다.
- 본문 설명·스토리·캐릭터 고유명사 등은 미번역 원문을 유지한다. 이 범위를 English 선택 아래에도 표시한다. 이미지 속 글자를 새로 그리거나, 읽기 전용 데이터/스토리 조회 키를 번역 문자열로 바꾸지 않는다.

영문이 길어지는 메인 바로가기는 `Story`, `Train`, `On duty`, `Solo`처럼 짧게 표시한다. 프로필은 `Gobi`로 줄여 320px에서도 글자가 잘리지 않게 한다.

## 구현

`game-language.js`가 값 검증·저장·복원·번역 사전·언어 구독 API를 제공한다. `language-settings.js`가 기존 설정의 스크롤 영역 맨 위에 선택 영역을 추가하고 기존 볼륨/확인/닫기 이벤트를 유지한다. `language-settings.css`는 현재 크림·남색 설정 디자인에 맞춰 두 개의 44px 이상 버튼을 제공한다.

번역은 메인·설정·공통 크롬처럼 명시한 표시 영역에만 적용한다. 전체 문서의 문자열을 반복 감시하거나 전투/캐릭터 데이터를 수정하지 않는다. 메인 갱신과 오디오·연출 버튼 자체의 원래 렌더러에도 번역을 연결해, 동작 후 한국어로 되돌아오는 현상을 막는다. 초기 언어는 이미지 로딩을 추가하지 않는다.
