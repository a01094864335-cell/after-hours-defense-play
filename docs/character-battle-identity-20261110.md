# 고비·찌릿 전투 외형 통일 — 2026-11-10

[얼굴·기존 전신·새 전신 비교 및 실제 전투 캡처](../qa/battle-identity-20261110/index.html)

메뉴의 승인된 얼굴을 기준으로 두 캐릭터의 실제 전투 원화를 교체했다. 고비의 예전 민머리, 찌릿의 주황 도마뱀 외형이 메뉴와 달랐던 문제가 대상이다.

| 인물 | 유지한 식별 요소 | 새 전신 |
| --- | --- | --- |
| 고비 | 연두 피부, 갈색 풍성한 머리, 황금 눈, 뾰족한 귀 | 흰 셔츠·버건디 조끼, 장부와 동전 주머니 |
| 찌릿 | 밝은 얼굴, 금발 곱슬머리, 노란 작업모, 파란 고글 | 노란 재킷·남색 작업복, 장갑과 전기 공구. 도마뱀 꼬리·비늘 제거 |

## 적용과 유지 범위

- 메뉴·목록·선택 스킬의 얼굴 중심 초상은 그대로 사용한다.
- 두 인물의 전투 보드, 직원 스킬 컷인, 로딩 대체 전신은 새 원화로 연결한다.
- 대기·눈깜빡임·준비·공격·스킬·회복 6포즈를 각각 제작했다. 바닥 기준점을 고정하고 모든 포즈의 최대 폭·높이로 셀 안전 영역을 계산한다.
- 다른 캐릭터의 전신 원화를 전량 교체한 작업은 아니다. 나머지는 기존 공통 얼굴 표시를 유지한다.
- 소환·합성·공격·스킬 수치, 좌표, 선택 동작, 저장 형식은 유지한다.

## 원본과 재현

`designs/battle-identity-20261110/*-master.png`는 공통 초상을 참조해 생성한 투명 배경 원본이다. `python scripts/export-matching-battle-sprites.py`로 WebP와 메타데이터를 기계적으로 내보낸다(Pillow·ImageMagick 필요). `assets/character-motion/manifest.js`를 기존 모션 정의 다음에 로드해 해당 두 ID만 덮어쓴다. 원본·검수 자료는 배포 패키지에서 제외한다.

- 320×568, 390×640, 390×844, 430×932에서 전투·두 컷인을 캡처했다. 스크립트 오류·누락 자산 0건.
- 공개 URL은 환경 프록시 제약으로 직접 재촬영하지 못했다. 같은 소스의 로컬 실행 및 배포 패키지 검사 결과다. 배포 성공 여부는 GitHub Actions에서 별도로 확인해야 한다.
