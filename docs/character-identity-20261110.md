## 확인한 원인

- 메인 기본 5명은 `lobby-reference.webp`에서, 도감 편성표는 별도의 `roster-reference.webp`에서 얼굴을 잘라 썼다. 같은 ID라도 표정·투구·고글·얼굴 비율이 독립적이었다.
- 훈련소는 처음 3명만 또 다른 `training-reference.webp`에서 잘라 썼고 나머지는 픽셀 전신 이미지였다.
- 편성을 바꾸거나 지원을 장착하면 기존 픽셀 전신으로 돌아가 메인 초상과 그림체·얼굴 구도가 달라졌다.
- 예전 전투 원화의 고비는 갈색 머리가 없고, 토르크는 고글과 다른 머리 형태였으며, 뽀득은 모자가 있었다. 찌릿도 메인의 노란 모자·파란 고글 얼굴과 다른 모습이었다.

## 적용 방식

`character-portraits.js`가 캐릭터 ID를 유일한 초상 파일에 연결한다. UI용 `staffPortraitPath`·`mercPortraitPath`, 인사기록의 `image`, 메인·도감·훈련 어댑터가 이 정의를 공유한다. 도감 편성표 이름은 이미지에서 잘라내지 않고 DOM 텍스트로 표시한다.

전투 보드와 직원 스킬 컷인은 같은 얼굴을 사용한다. 후속 작업으로 고비·찌릿은 공통 얼굴을 참조한 새 전신 6포즈로 연결했다([상세](character-battle-identity-20261110.md)). 나머지 직원은 공통 얼굴 표시를 유지한다. 기존 등급·기절·재사용 대기 표시와 선택·방향 전환을 보존하고, 공격 시 작은 기울기·기존 부유 움직임을 사용한다. 캐릭터 ID, 소환/합성/공격/범위/수치/600×600 좌표와 저장 형식은 바꾸지 않는다. 로딩 중 예전 전신이 잠깐 나타나는 대신 공통 초상의 준비를 기다리며, 필요한 얼굴을 캐시한다.

## 원화와 자산 범위

- 새 초상 24개는 투명 배경 512×512 WebP이며 전체 용량은 약 1.05 MiB다. 얼굴 중심 구도와 남색 외곽선·밝은 채색·흰 외곽 여백을 공유한다.
- 생성 원본 4장은 `designs/character-identity-20261110/`에 보관했다. 각 장은 3×2 시트이며 인물 순서와 자르기 좌표·해시는 manifest에 기록했다. 배포에는 원본 시트를 넣지 않는다.
- 메인·도감·상점·훈련소의 승인된 큰 장면, 배경·종이·로고·버튼·아이콘은 유지했다. 장면 속 다른 자세는 같은 인물의 구도 차이로 다루며, 작은 초상을 다시 별도로 잘라 쓰지 않는다.
- 이야기 패널 전체와 적·군단장·마왕 원화를 전량 재생성한 작업은 아니다. 이들은 대사/사건의 구도 또는 다른 인물의 자산이다. 이번에 통일한 범위는 플레이어 직원·지원의 식별용 얼굴과 실제 표시 경로다.
- 과거 시안·픽셀 원본·모션 메타데이터는 이력과 호환을 위해 보존했다. 새로운 화면에서 이 원본을 직접 초상으로 재사용하면 불일치가 재발하므로 공통 경로를 사용한다.

## 검증

- Node 기능 테스트 76개, 배포 패키지의 브라우저 테스트 18개 통과.
- 편성 직원을 바꿔 17명 전체를 순회하며 메인과 도감이 같은 초상을 사용하는지 검사했다. 직원 17개·지원 7개의 훈련 행, 지원 7종 장착, 고비 상세와 지원 채용 결과도 검사했다.
- 전투가 실제 공통 고비 얼굴을 그리는지와 셀 좌표 불변을 검사했다. 모션 처리기가 새 얼굴을 예전 전신 캔버스로 되돌리지 않도록 했다.
- 17종 × 6포즈 × 4크기 = 408조합에서 실제 얼굴 알파 픽셀과 상태 텍스트 충돌 0건, 상태 글자·그리드 문제 0건. 측정 중 게임 시간이 진행되지 않도록 고정했다.
- 320×568·390×844·430×932의 주요 메뉴 캡처에서 스크립트 오류와 누락 자산 0건. 전투·전체 컷인은 390×640을 포함한 4크기로 추가 캡처했다.
- 직접 공개 URL의 재촬영은 환경 프록시 제약이 있어 같은 소스의 로컬 및 배포용 빌드로 검증한다. [기계 판독 검증 요약](../qa/character-identity-20261110/summary.json).

## 이후 캐릭터 애셋을 수정할 때

1. 같은 인물을 이름만 적어 따로 생성하지 않는다. 기존 공통 얼굴과 큰 장면 원화를 참조하고 위의 식별 요소를 함께 지정한다.
2. 표정/포즈 변형은 피부·머리·모자·귀·고글·종족이 바뀌지 않는지 확인한다. ID가 같으면 화면도 같은 파일 경로를 사용한다.
3. 새 캐릭터는 registry, manifest, 얼굴 파일, 인사기록을 함께 추가한다. 잠김 실루엣과 지원 장착 상태도 확인한다.
4. 초상 변경 후 메인→편성→도감→상세→훈련→채용→전투→컷인을 연결해서 검수한다. 작은 화면의 상태 글자와 얼굴 안전 여백을 재검증한다.
