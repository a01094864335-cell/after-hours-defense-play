# 재미·난이도 우선순위 개선 및 메인 고비 수정 — 2026-11-23

기준 공개 버전은 main `84e71ed798fe319b5314119e97171a50b753be67`이다. 사용자가 평가의 개선 우선순위 적용을 요청했고, 작업 중 메인 고비의 배경 이질감·손 자세도 함께 수정하도록 요청했다.

## 1. 보상에서 판을 바꿀 선택권 제공

- 새로 생성하는 정식 당직 5·15웨이브 보상은 3개 중 직접 고른다. 카드를 누르고 확인해야 받으며, 선택 상태도 저장한다. 키보드 선택 후에도 해당 카드의 포커스를 유지한다.
- 기존 보상 종류·수량은 유지한다. 첫 5웨이브에는 SP 보급·당직 전략·합성 보험 등이 실제 상태에 맞춰 제시된다. 15웨이브에도 원래 성장·상황 보상 중 필요한 것을 직접 고른다.
- 전략 카드를 선택하면 다음 화면에 **연쇄 잔광 / 정산 특근 / 비상 방벽** 세 가지가 나온다. 당직당 전략 1개 제한은 유지한다. 정산 특근은 편성 서기 또는 장착 회계사가 있어야 고를 수 있다. 선택 불가능한 이유도 표시한다.
- 화면당 보상 3개 규칙을 유지한다. 전략의 세부 선택도 별도 화면의 3개 버튼으로 제공한다.
- 다른 5배수 구간은 1/3 룰렛을 유지한다. 이때 전략 보상도 조건에 맞는 연쇄·정산·방벽 중에서 생성되므로 방벽이 후보에서 빠지던 문제를 해결했다.
- 이전 저장에서 이미 추첨된 5·15웨이브 보상은 결과와 종류·대상·수량을 보존한다. 보상 모드가 없는 과거 저장도 기존 룰렛으로 처리하며 새 선택권으로 교환하지 않는다.
- 잘못된 선택 인덱스·저장 데이터는 상태를 바꾸기 전에 거부한다. 중복 수령·다른 탭 저장 권한·재접속 정산 방지는 기존 경로를 사용한다.

## 2. 합성 성장 체감 조정

직접 평타의 등급 계수와 스킬 등급 계수를 분리했다. 튜토리얼은 기존 곡선을 유지한다.

| 결과 등급 | 기존 평타 계수 | 새 정식 당직 평타 계수 | 같은 직군 두 명을 한 명으로 합칠 때 평타 합계 변화 |
| --- | ---: | ---: | ---: |
| ★1 | 1.00 | 1.00 | — |
| ★2 | 1.05 | 1.05 | +5% |
| ★3 | 1.20 | 1.40 | 약 0% |
| ★4 | 1.50 | 2.10 | 약 0% |
| ★5 | 2.00 | 3.10 | 약 -8% + 고유 스킬 해금 |
| ★6 | 2.70 | 4.80 | 약 -7% |
| ★7 | 3.80 | 7.60 | 약 -8% |

공격 간격이 등급에 비례해 짧아지는 기존 규칙까지 포함한 비교다. 표는 같은 직군·같은 장비라는 가정의 **직접 평타**이며 범위·연쇄·표식·화상·스킬·인접 버프·경제 생산 효과를 합산한 보장은 아니다. 결과 종류는 기존처럼 무작위다.

- 저등급에서는 같은 직군으로 나왔는데 평타 합계가 약해지는 현상을 줄였다.
- 고등급에는 스킬과 빈칸 가치의 대가를 남기되, 기존의 큰 평타 손해를 줄였다.
- 스킬·화상·서기 수입의 등급 계수, 합성 성공률 95→70%, SP 환급·가격·재화·영구 훈련 배율은 유지했다.
- 합성 미리보기에서 실제 현재 등급의 ‘동일 직군이면 평타 총화력 ±%’를 보여준다. 운영·지원 직원이나 비교할 수 없는 직군은 별도 안내한다.

## 3. 청소부 × 전기기사 협업

- 청소부의 평타가 감속을 줄 때 적에게 젖음을 남긴다. 기본 2초이며 기존 청소 훈련 시간 증가를 반영한다.
- 대청소도 해당 적에게 적용되는 이동 정지 시간만큼 젖음을 남긴다. 군단장 저항을 반영하고 최대 3초로 제한한다.
- 젖은 적에게 전기기사가 주는 직접 공격·스킬 피해는 20% 증가한다. 다른 직원·공유된 전달 피해에는 새 배율을 또 적용하지 않는다.
- 여러 청소부는 지속 시간을 갱신하며 20% 배율을 누적하지 않는다. 일시정지와 저장/복원에서도 지속 시간을 보존한다.
- 튜토리얼에는 적용하지 않는다. 캐릭터 능력 소개와 선택 미리보기에는 한국어/영어 협업 설명을 제공한다.
- 적 체력바 옆의 푸른 표시와 기존 연쇄 이펙트·‘협업 +20%’ 텍스트를 활용한다. 같은 적의 텍스트는 0.6초 제한을 둔다. 새 대형 이미지나 프레임별 DOM 애니메이션은 추가하지 않았다.

## 4. 실제 플레이를 분석할 기록 마련

기기 안에 최근 20개 완료 기록을 저장한다. 서버 전송은 추가하지 않는다. 결과의 **당직 분석 → 성장과 협업 → 플레이 기록 저장**에서 내려받는다.

- 웨이브 1·5·10~20·25·30 진입 시점의 SP·직원 수·최고 등급·장비 합계·일반 합성 가능 쌍·전략.
- 보상 구간·직접 선택/룰렛·선택 보상·전략·시각.
- 최근 돌파 적·군단장 여부·남은 체력·시각·SP·직원 수·합성 가능한 쌍·전략.
- 최근 합성의 등급·직군·성패 및 합성 후 전투시간 10초 안의 돌파 횟수.
- 협업 발동 횟수·추정 추가 피해, 아이템 사용, 종료 형태(패배/퇴근/연수).
- 기존 기록의 덱·지원·훈련·변주·마왕 출동·보스 처치 시간도 함께 내보낸다.

결과 화면의 비교는 같은 훈련 수준과 같은 변주의 기록을 대상으로 한다. 덱·지원·아이템·마왕 개입 등 다른 조건도 내보낸 자료에서 확인해야 한다. **합성 직후 돌파와 최종 돌파 적을 패배의 단독 원인이라고 단정하지 않는다.** 협업 추가 피해는 실효 피해를 이용한 추정치다.

과거 저장에 관측 필드가 없으면 불완전한 기록임을 표시하고 새 비교 기준에 섞지 않는다. 필드 수와 배열 길이를 제한하고, 잘못된 관측 값도 저장 복원 전에 검증한다. 관측을 위한 추가 저장 쓰기는 만들지 않고 기존 보상·합성·웨이브 저장에 함께 기록한다.
