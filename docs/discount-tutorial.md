# 최초 반값 소환 체험

신입 연수의3번째 공격 안내에 포함한다. 기존 사용자의 일반 당직, 실제 합성 확률,10웨이브 수료 조건은 유지한다.

1. **실패 예시 확인:** 같은 직원 두 명의 모형을 보여준다. 실전에서는 이동한 직원1명이 사라지고 다음 소환이50% 할인된다고 설명한다. 모형 시연에는 실제 직원이 소모되지 않는다.
2. **할인 비용 확인:** 모형 하나를 흐리게 표시하고, 실제 다음 소환 할인1회를 제공한다. 기본 비용과 실제50% 비용을 숫자로 안내한다. SP가 모자라면 연습에 필요한 차액만 지원한다.
3. **실제 소환:** 안내를 닫으면 소환 버튼을 강조한다. 실제 SP가 차감되고 직원이 배치돼야 완료된다. 완료 안내에서 사용한 비용과 다음 기본 비용을 확인한다.

안내에는 건너뛰기를 제공한다. 건너뛰기는 연수 수료나 수료 보상을 지급하지 않는다. 이미 시연 후 받은 할인은 건너뛰어도 유지한다. 자리가 없거나 SP가 부족해 소환에 실패하면 과정은 완료되지 않고 할인도 보존한다.

진행 단계는 전투 저장에 포함한다. 안내1·2단계는 재접속 시 같은 단계로 열며, 실제 소환 대기 중이면 저장된 반값과 강조를 유지한다. 기존 저장에 이 단계가 없으면 과거 플레이를 방해하지 않도록 완료 취급한다. 연수 재도전도 체크포인트의 안내 단계로 복구한다.

검증: 실패 모형이 실제 직원을 제거하지 않음, 실제50 SP 차감/기본110 SP 증가, 단계별 재접속, 할인 중복 지급 방지, 건너뛰기/수료 분리, 일반 사용자 비활성, 소환 실패 보존과 기존 저장 호환. 320/360/390px 화면도 확인한다.
