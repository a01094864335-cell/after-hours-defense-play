# Android 화면 초기화 호환성 수정

안드로이드에서 게임이 표시되지 않는다는 제보를 받아 두 가지 기능 제한 환경을 재현했다. 제보 기기와 브라우저 버전은 확인되지 않았으므로 아래 재현을 실제 기기의 확정 원인으로 단정하지 않는다.

- `dvh`를 지원하지 않는 환경: 게임의 기준 폭이 `min(100vw,56.2799dvh)`로 정의돼 있어 계산이 무효화되고, 게임 영역이 0×0px로 줄어들었다. 기준 단위를 기본 `vh`로 두고 `@supports`로 확인한 경우만 `dvh`를 사용하도록 수정했다. 대화상자와 전투 화면의 높이도 같은 단위를 사용한다.
- `MediaQueryList.addEventListener`가 없고 구형 `addListener`만 있는 환경: 절전 정책 초기화가 예외를 던지고 후속 게임 초기화도 멈췄다. 절전 모드와 화면 회전 감지 모두 구형 리스너 방식으로도 연결한다.

Playwright의 Pixel 5 Android UA·터치·기기 배율 환경에서 로비 진입, 전투 화면, 직원 소환을 확인했다. 기능 제한 테스트는 CSS 응답의 `dvh`를 미지원 단위로 바꾸고 `MediaQueryList.addEventListener`를 제거해 같은 오류를 재현한다. 수정 뒤 393×698px 게임 영역, 정상 초기화, 터치 소환 및 회전 안내의 표시·해제를 확인했다. 실제 Android 기기 또는 구형 브라우저 엔진을 직접 실행한 결과는 아니다.

최신 문법, 기본 HTML dialog 및 Web Locks 지원은 여전히 필요하다. Web Locks가 없는 환경에서는 기존 저장 보호 정책대로 게임 저장 연결 안내를 표시하며 저장 보호를 우회하지 않는다. 같은 문제가 남는다면 브라우저 이름·버전과 빈 화면/로딩/저장 안내 중 어떤 상태인지 확인해야 한다.

배포 캐시 키: `android-compat-1`.
