# 최초 플레이 튜토리얼 운영안

반값 소환 체험은 신입 연수3번째 공격에 반영했다. 실패 모형 확인→할인 비용 확인→실제 반값 소환의3단계다. 아래의 전체 안내 재구성은 후속 제안이며, 기존10웨이브 연수 구조는 유지한다.

## 권장 운영: 짧은 직접 조작 안내 + 상황별 추가 설명

처음부터 규칙을 모두 설명하기보다 약2~3분 안에 소환·합성·스킬·보상 한 번을 직접 경험하게 한다. 안내는 한 번에 목표 하나, 설명1~2줄, 강조할 조작 하나만 보여준다.

| 순서 | 직접 하는 행동 | 안내 예시 | 완료 판정 |
|---|---|---|---|
| 1 | 직원 소환 | '소환을 눌러 첫 직원을 배치하세요. SP는 전투 중 쓰는 자원이에요.' | 직원1명 배치 |
| 2 | 당직 시작·적 처치 확인 | '직원은 자동으로 공격해요. 지금은 방어선을 지켜보세요.' | 첫 처치 |
| 3 | 같은 종류·등급 합성 | '직원 하나를 선택하고 같은 직원 하나를 누르거나 끌어 놓으세요.' | 실제 유효 합성1회 |
| 4 | 장비 강화 | '장비는 같은 직군 전체를 강화해요. 이번엔 경비원을 강화해보세요.' | 장비1회 강화 |
| 5 | 5등급 직원 선택·스킬 | '5등급 직원을 고른 뒤 스킬을 누르세요. 충전이 끝나면 다시 쓸 수 있어요.' | 스킬1회 사용 |
| 6 | 첫 군단장과 보상 | '위험 표시가 뜬 칸을 확인하세요. 군단장을 넘기면 보상 하나를 고를 수 있어요.' | 첫 단계 보상 선택 |

연습용 같은 직원2명·강화용 SP·스킬 체험 직원은 해당 단계에 맞춰 제공하는 안을 권한다. 첫 합성은 성공 경험을 보장하되 **연습 조건임을 명시**한다. 실제 규칙을 바꾸거나 실패를 숨기지 않는다.

반값 소환은3번째 연수에서 별도 과정으로 체험한다. 연습 모형의 실패는 확률 판정이 아니며 실제 직원은 소모하지 않는다고 명시한다. 할인1회와 필요한 연습 SP만 지원하고, 실제 소환 성공으로 완료한다. 3배속 안내는 기본 조작 후 짧게 소개하는 후속 제안이다.

## 화면과 진행 방식

- 설명을 읽을 때는 정지, 직접 전투를 관찰하는 구간에서는 진행한다. 자동으로 사라지는 설명은 쓰지 않는다.
- 버튼을 누른 사실보다 실제 배치·합성·강화 성공을 완료 조건으로 삼는다. SP 부족이나 꽉 찬 보드에서 막히면 부족한 조건부터 안내한다.
- 잘못 누르면 진행 상황은 유지하고 올바른 대상만 다시 강조한다. 전체 초기화는 하지 않는다.
- 건너뛰기와 메뉴의 다시 보기를 제공한다. **안내 건너뛰기와 연수 수료를 분리**해 수료 보상·편성 해금은 실제 수료 조건을 따른다.
- 안내 단계와 완료 여부는 저장해 재접속 시 이어간다. 전투 저장과 충돌하지 않도록 같은 체크포인트를 사용한다.
- 기존 사용자에게 강제로 처음부터 다시 보여주지 않는다. 새 시스템인 반값 소환·강화 보상만 짧은 변경 안내로 제공하는 안을 권한다.
- 320px에서 본문14~16px, 버튼44px 이상. 긴 설명은 도움말로 보내고 연습 화면은 한 행동만 남긴다.

## 도입 후 확인할 지표

첫 소환까지 걸린 시간, 각 안내 단계 중단률, 합성 조건 오류 횟수, 첫 군단장/5단계 돌파율, 안내 건너뛰기 비율을 확인한다. 수집 기능은 이번 변경에 넣지 않았다. 초기에는 소수 플레이테스트로 먼저 막히는 구간을 확인하는 것이 좋다.
