# A안: 캐릭터 소환 무대형 상점

실제 게임 기준 저장소 `after-hours-defense-play`, 최신 전투 D 레이아웃이 포함된 main 위에 적용했다.

## 화면

- 제목·코인·닫기를 한 줄에 모으고, 채용팩·개별 아이템 탭을 크게 표시한다.
- 채용팩에서는 단체 캐릭터 무대를 크게 보여주고, 하단에 확률 상세·채용 포인트·지원 보장·구매·직원 도감을 모았다.
- 지원 보장은 기존 실제 값으로 10칸을 표시한다. 미보유 지원이 없는 경우에는 기존의 지원 수집 완료 상태를 표시한다.
- 개별 아이템은 기존 상품과 구매 버튼을 유지한다. 좁은 화면에서는 본문만 스크롤하며 헤더와 탭은 남는다.

## 기능 유지

`buyStaffPack`, 가격 120코인, 일반 90% / 지원 10%, 중복 포인트·미보유 지원 보장·채용 이야기·저장·개별 아이템·직원 도감 로직을 변경하지 않았다. 기존 노드와 클릭 핸들러를 유지한다. `approved-ui.js`의 화면 표시 계층만 기존 잔액 문자열을 두 칸과 진행 표시로 정리한다. 진행 칸은 장식이며 읽을 수 있는 텍스트 값을 함께 제공한다.

`dialog-layout.js`는 헤더로 이동한 코인을 다시 본문으로 옮기지 않도록 기존 모달 구성 책임을 유지한다. `scripts/build-pages.cjs`는 두 WebP 배경을 배포 파일에 포함한다. 이미지에는 게임 조작이나 문구가 들어 있지 않다.

## 검증

- `node --test tests/*.test.cjs`: 71개 통과.
- `node scripts/build-pages.cjs /tmp/after-hours-shop-stage-pages`: 배포 빌드.
- 빌드에서 `python3 -m unittest discover -s tests -p test_browser_smoke.py -v`: 11개 통과.
- `node scripts/check-shop-stage.cjs`: 320×568, 375×667, 390×724, 390×844, 430×932에서 부족 코인, 지갑 표시, 확률 상세, 아이템 구매, 채용팩 구매·지원 보장, 채용 이야기 후 도감 진입 확인. JS 오류·애셋 누락·가로 넘침 없음.
- 캡처·상태 기록은 `qa/shop-stage/`에 있다. 캡처의 11코인·2포인트·보장 1/10은 격리된 브라우저의 테스트 저장값이다.
