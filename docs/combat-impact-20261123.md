# 전투 임팩트 강화 · 2026-11-23

사용자가 요청한 다섯 항목과 앞서 요청한 훈련소 단순화를 함께 반영한다. 여기서 ★5는 영구 훈련 Lv.5나 전투 장비 Lv.5가 아닌, **보드 직원의 합성 등급 5**다. 기존 고유 스킬 해금 시점과 일치한다.

## 2. 선택 말풍선 제거

직원 클릭 시 길게 뜨던 설명/추천 합성 말풍선을 제거했다. 선택 테두리와 하단의 캐릭터 이름·등급·스킬 버튼은 유지한다. 하단에 긴 스킬명 대신 캐릭터 이름을 표시해 버리기·사용 버튼과 경쟁하지 않게 했다.

실제로 드래그해 합성할 때의 성공/실패 확인은 유지한다. 클릭만 해도 뜨는 설명과 구분했다. 재배치·합성·버리기·스킬 사용·도움말 기능은 그대로다.

## 3. 등장·합성·소멸 이펙트

- 등장: 바닥 링, 짧은 착지 스쿼시, 직군 색상과 문양의 팝 효과.
- 합성 성공: 확장 링, 금빛 잉크형 버스트, 별 등급 표시. ★5부터 새 외형으로 전환.
- 합성 실패: **사라지는 출발 직원**의 모습을 잠깐 띄우고 기울어진 퇴장, 연기·별과 짧은 `앗! / OOPS!` 표시. 대상 직원은 그대로 유지한다.
- 직원 버리기: 해당 인물의 모습과 짧은 퇴장 효과. 기존 이중 확인·SP 미반환 유지.
- 적 처치: 해당 적의 모습을 짧게 튕겨 사라지게 하고 연기와 별 파편을 추가.

직원은 현재 HP로 죽는 시스템이 없으므로 새 사망 규칙을 만들지 않았다. 실제 직원 소멸 경로인 합성 실패/버리기와 적 처치를 강화했다. 직군별 색과 편지·방울·번개·기어·별·달 등 문양을 사용한다. 기존 직업 스킬 이펙트와 효과음은 유지한다.

## 4. 군단장 알림

4·9·14웨이브의 조기 경고 대신 **5·10·15… 웨이브 시작**에 알린다. 실제 저장된 군단장 계획의 이름과 모습을 사용한다. 배너는 금빛 하프톤·두꺼운 잉크 그림자·짧은 팝 애니메이션을 사용하며 텍스트는 DOM/CSS로 관리한다. 한·영 문구를 제공한다.

알림은 활동 중 약 3.2초 표시되고 끝부분에서 사라진다. 일시정지/다이얼로그/숨겨진 탭에서는 기존 경고 타이머 정책에 따라 멈춘다. 작은 화면에서는 배너를 낮게 줄인다. 군단장 배너 동안 일반 메시지만 숨겨 겹침을 방지하고, 남은 적 계기판은 유지한다. 일반 메시지/아이템 안내도 같은 크림색 카툰 쪽지 계열로 맞췄다.

## 5. 적의 통통 이동

진행 거리에 맞춰 작은 점프와 착지 스쿼시, 발밑 그림자 크기 변화를 추가했다. 일반 적은 가볍게, 중갑/군단장은 낮게 움직인다. 감속하면 보폭도 느려지고 이동 정지 상태에서는 점프를 멈춘다.

변경은 **그림 위치/비율에만** 적용한다. 실제 경로 좌표, 이동 속도, 공격 사거리, 타격 판정, 적 HP·보상은 바꾸지 않는다. 런타임 시각 연출에 게임 난수를 추가하지 않는다.

## 성능·접근성·검증 범위

- 강화 WebP 17개는 ★5가 화면에 등장할 때 개별 로드한다. 최초 로비에서 다운로드하지 않는다. 로드 중에는 기존 전신으로 표시해 빈 칸이 되지 않게 한다. 생성 원본 PNG는 배포 패키지에 넣지 않는다.
- 캔버스·기존 FX 배열을 사용하며 매 프레임 DOM 입자를 만들지 않는다. 신규 주요 효과는 FX 수가 480 이상이면 추가하지 않는다. 절전 모드에서는 입자 수를 줄인다.
- 동작 줄이기 설정에서는 점프·스쿼시·회전·배너 팝을 끄고 정적인 식별 피드백을 유지한다. 전체 화면 흔들기나 반복 화면 섬광은 추가하지 않았다.
- 새 외형/아틀라스 경계, 정확한 웨이브 시작·일시정지, 실제 스킬 클릭, 실패 손실/환급·버리기 확인, 그림 전용 점프와 RNG 비침습성 검사를 추가했다.
- 실제 모바일 320×568 / 390×844 / 430×932에서 일반/★5/나머지 직군/선택/군단장 5·10·15/효과 재현 상태를 캡처했다. 상태 재현용 테스트 보드이며 공개 이용자의 실제 저장 파일이나 수동 완주 기록이 아니다.
- 공개 호스트 접근은 실행 환경에서 제한되어, 캡처와 E2E는 공식 Pages 패키지의 로컬 실행 기준이다. 공개 배포는 GitHub Actions 성공과 URL로 별도 확인한다.

## 배포 게이트 후속 정비

배포 검사에서 기존 인물 일치 검사가 제거된 훈련 목록을 계속 요구하던 두 항목을 발견했다. 인물 검사는 도감·편성·상세에 옮겨 **일반 17명/지원 7명** 전부를 계속 대조한다. ★5 전투 출처는 새 아틀라스 디코딩을 명시적으로 기다린 후 검증하고, 일반 전신 출처는 ★4에서 검증해 로딩 타이밍에 따라 결과가 달라지지 않게 했다.

외곽선 검사도 일반 17종과 강화 17종으로 확장했다. 두 크기·6개 애니메이션 상태의 **408개 실제 픽셀 렌더링**과 두 보드(일반/강화 각 15명) 반복에서 **warm canvas 추가 생성 0개**를 확인했다. 기존 13명 외곽선 마스크의 SHA 일치 검사도 유지했다. 전체 배포 스모크 **37개**, 인물 검사 **5개**, 확장 외곽선 검사 **2개**가 로컬에서 통과했다. 런타임 코드와 애셋은 이 후속 정비에서 변경하지 않았다.
