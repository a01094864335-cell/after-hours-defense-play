# 전투 UI: 마왕성 야간 경계

전투 화면의 기준은 **먹색 돌벽 · 낡은 황동 · 청록색 선택 표시**다. 기존 직원 일러스트를 유지하고 전장과 조작부를 한 가지 재질로 맞춘다.

## 역할과 제작 규격

- `ui.css`의 Night watch 구간이 전투 화면의 배치·타이포·버튼 상태를 소유한다. 새 보정 CSS나 `!important` 스킨을 추가하지 않는다.
- `assets/night-watch/arena.webp`는 기존 전장의 공간 구성을 참조해 만든 전용 픽셀풍 전장이다. 600×600 월드에 맞춰 표시한다. 벽돌, 회랑, 기둥, 횃불, 입구, 왕좌를 포함한다. 텍스트는 Canvas가 그린다.
- 전장은 이미지 생성 후 WebP로 최적화했다. 버튼과 패널은 직접 작성한 SVG 9-slice다. 원본 모서리 16 단위를 사용하고 화면에서는 9~12px 두께로 표시한다. 재질과 금속 테두리를 CSS 그라데이션으로 다시 그리지 않는다.
- 슬롯은 76×88이며 일반·선택·합성 가능 상태를 각각 가진다. 선택은 황동, 합성 가능 표시는 청록색이다.
- `battle-art.js`는 전투를 그릴 때만 필요한 이미지를 읽는다. 전장은 기존 정적 Canvas 캐시에 들어가며 로드 완료 시 한 번 다시 그린다. 로딩 중에는 Canvas 기본 슬롯을 사용한다.

## 좌표와 피드백

600×600 월드, 5열×3행 슬롯, 이동 경로, 포인터 좌표 변환, 게임 규칙과 저장 형식은 유지한다. 최신 D 레이아웃의 선택 직원·스킬 → 소환 → 아이템 순서와 `BattlePresentation` 투영을 유지한다. 캐릭터 비율을 유지하며 보드가 세로 공간을 채우고, 터치는 같은 투영의 역변환을 사용한다.

소환 성공 시 바닥 링을 표시하고, 합성 성공 시 링·파편·새 등급을 표시한다. 실패·자원 부족에는 성공 효과를 넣지 않는다. 효과는 기존 게임 시간과 `fx` 수명을 사용하므로 일시정지와 함께 멈춘다. 모션 감소 설정에서는 이동하는 파편과 확장 애니메이션 대신 정적인 링과 등급 표시를 사용한다.

## 확장 방법

다음 화면을 바꿀 때는 전투 화면에서 정한 재질·색 역할·모서리 규격으로 시안을 먼저 확정한다. 상점은 계약·파견, 도감은 인사기록부, 결과는 근무보고서라는 설정을 형태와 아이콘에 연결한다. 한 화면을 승인한 다음 부품을 재사용하고, 화면마다 새 스킨을 만들지 않는다.

검증: `node --test tests/*.test.cjs`, `node scripts/build-pages.cjs /tmp/game-pages`, 배포 산출물 대상 `test_browser_smoke.py`. 모바일에서는 320×568부터 430×932까지 조작부, 15칸 터치·드래그, 일시정지, 고등급 스킬, 모션 감소를 확인한다.
