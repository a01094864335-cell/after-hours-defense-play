# 전투 화면 D 레이아웃

승인된 D안의 하단 순서를 **선택 직원·스킬 → SP·소환·장비 → 아이템**으로 적용했다. 아이템은 이름 대신 아이콘과 보유 수량을 표시하며 접근성 이름에는 아이템명과 수량을 유지한다.

상단 HUD 바로 아래 알림 영역은 상시 확보한다. 보스 예고와 아이템 안내도 이 영역을 공유하여 보드나 버튼을 밀어내지 않는다. 전체 안내는 정보 버튼으로 확인한다. 지원 영웅과 보드 제목 등 중복 문구는 숨긴다.

## 보드 표시와 입력

`battle-presentation.js`는 기존 600×600 전투 좌표를 화면에 투영한다. 배경과 칸은 세로 공간을 채우고 캐릭터와 글자는 별도로 그려 비율을 유지한다. 클릭·터치·배치 미리보기는 같은 투영의 역변환을 사용한다. 전투 범위, 경로, 저장된 배치는 기존 좌표를 유지한다. `app.js`의 기존 resize 콜백도 새 표시 크기 계산에 위임한다.

## 확인 자료

`qa/battle-d/`에 320×568, 375×667, 390×844, 430×932의 선택/미선택/보스 예고/합성 미리보기 캡처와 자동 확인 결과가 있다. 캡처는 재현용 전투 상태를 주입한 브라우저 화면이다. 선택, 보스 예고 전후 보드·버튼 영역 크기가 같고 모든 15칸 터치 선택 및 실제 터치 드래그 합성이 동작하는지 확인한다.

재현: `UI_BASE_URL=<게임 주소> node scripts/check-battle-d.cjs`

검증: Node 회귀 테스트 71개, 패키징한 게임 브라우저 테스트 11개, 성능 회귀 테스트 8개. 성능 테스트는 브라우저 자동 검증이며 실제 단말 배터리·프레임 측정은 포함하지 않는다.
