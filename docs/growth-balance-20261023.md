# 성장 밸런스 1차 조정 · 2026-10-23

기준 공개 버전 bf78b3a. 기존 영구 훈련·고용·재화 저장 형식은 유지한다. 기존 판의 적 HP는 저장 스냅샷을 유지하므로 비교는 새 판으로 한다.

## 적용 정책

- 영구 직원 훈련: (1 + 장비 추가 보너스) × (1 + 0.8 × (훈련Lv−1)/29). Lv30은 어느 장비 레벨에서도 기본 피해1.8배. 캐릭터별 마일스톤은 별도로 적용한다.
- 서기 기본 수입과 예산 스킬은 장비 효과와 별도로 영구Lv30에서1.4배. 5회마다 지급하는 고유 정산은 추가 적용한다.
- 청소부 감속은 기존 마일스톤에 연속 성장을 더한다. 최대 훈련 시 일반 이동 배율0.40, 군단장0.68. 감속 지속 시간은 기존 마일스톤을 따른다.
- 등급 추가 피해: 1/1.05/1.2/1.5/2/2.7/3.8. 기본 공격과 피해 스킬에 적용한다. 화상 기본 피해에도 한 번 적용한다. 공격 속도의 기존 등급 효과와 별도이다. 고정 비율 표식·수입·지원 효과 전체를 이 배율로 확대하지 않는다.
- 첫15차까지 기존 적 HP를 유지한다. 16차부터 일반 HP 증가율은16%→14.5%, 군단장은20%→15%. 15차 경계에서 불연속 점프가 없도록 구간별 곱셈을 적용한다.
- 합성 실패 확률, 영구 훈련 비용, 마왕의 등장·전멸 규칙, 지원 영웅 자체 성장 규칙은 기존 정책을 따른다.
- 훈련소·인사기록과 근무 안내에 새 계산 및 등급 보상을 표시한다.

## 검증

동일 자동 운영 및 초기 시드1~32, 직원/지원 훈련을 모두Lv1 또는30으로 설정. 기본5인 편성(경비/시설/청소/서기/전기), 비상 대응반, 마왕 포함, 일일 변형·소모품 제외. 빈 칸 소환 → 보드 충원 후 장비 우선 → 합성, 고등급 스킬 사용, 5차 보너스는 SP. 전투0.05초, 운영0.75초 간격. 변경 전후 각64판 총128판.

마왕·지원 없이 별도16회씩 검증: Lv1 평균30.81 / Lv30 평균38.75. 성장 차이가 마왕이나 특정 지원만으로 만들어지는 현상은 아니다.

기능 회귀 검증: 전투 프레임 간격별 공정성, 군단장 정체성/회복/보호막 상한, 훈련 구매와 저장 실패, 전투 시작 시 훈련 스냅샷, 합성 실패 확률, 초반 곡선 보존, 후반 곡선 연속성, 장비1~5에서 영구 성장 배율 동일, 서기 수입과 고등급 관통/화상 피해, 10차 튜토리얼, 상점과 GM 저장 분리.

남은 검증 범위: 신규12인 전체 조합, 상위 등급 집중 편성, 지원3종의 최적 보너스 전략과 장기 경제. 이번 패치는 성장 체감과 난이도 곡선의 1차 개선이며 모든 조합의 최종 밸런스 확정은 아니다.
