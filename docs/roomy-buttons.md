# 버튼 여백 및 외곽 정리

2026-11-02 · 공개 게임 after-hours-defense-play · 기존 기능과 라우팅 유지

## 원인과 변경

기존 44px 버튼은 12px 프레임 안에 20px 텍스트를 배치해 위아래 여백이 거의 없었다. 기본 최소 높이만 충족하는 방식 대신 실제 면 안쪽의 여백을 확보했다. 71개 UI SVG에 있던 #171020 외곽 도형은 9-slice에서 검정 띠처럼 늘어나 보였으므로 제거하고, 모든 PNG를 투명 배경으로 다시 출력했다. 버튼 CSS의 filter·box-shadow와 중첩 GNB 프레임도 제거했다. 이미지의 바깥 투명 영역을 검정색으로 채우지 않는다.

## 표시 규격

| 영역 | 최소 높이 | 텍스트/아이콘 여백 |
|---|---|---|
| 로비 당직 준비 | 76px, 320px 화면은 68px | 위아래 20~22px / 좌우 24~28px |
| 주요 액션 | 68px | 20px / 28px |
| 일반 팝업 버튼 | 60px | 18px / 24px, 좁은 화면 좌우 20px |
| 탭 | 56px | 16px / 20px, 좁은 화면 좌우 10px |
| 하단 GNB | 72px, 좁은 화면 64px | 10~12px / 12~18px, 아이콘과 문구 간격 6~8px |
| 로비 바로가기 | 60×72px, 좁은 화면 52×60px | 10~12px, 아이콘·문구 간격 6~8px |
| 메뉴·닫기 | 56px | 아이콘 주위 16px |
| 구매 버튼 | 76px | 18px / 20~24px, 가격·수량 최대 2줄 |
| 긴 도감 이동 | 80px | 20px / 24px, 최대 2줄 |
| 전투 소환 | 64px | 20px / 12~18px |
| 전투 스킬 | 56px | 16px / 20px |
| 전투 아이템 | 68px, 좁은 화면 76px | 14px / 10~12px |

8px 표시 테두리를 사용하고 버튼에는 border-image-outset을 두지 않는다. SVG/PNG 원본 픽셀 크기와 최대 줄 수의 기준은 기존 manifest에 유지하며 위 표는 실제 게임 표시 규격이다. 본문은 그대로 두고 버튼 내 글자가 작아지는 것으로 문제를 숨기지 않는다. 한 줄 전용 행동 버튼은 줄바꿈 없이, 구매/긴 이동은 지정한 2줄 부품을 사용한다. 복합 캐릭터 카드는 본문형 영역으로 유지한다.

## 검수

qa/roomy-buttons/after에 동일한 32개 UI 상태 × 3개 viewport와 스크롤 하단 캡처를 기록했다. 320×568, 390×844, 430×932의 Chromium 모바일 에뮬레이션이다. 짧은 화면에서 커진 훈련소 바로가기와 지원 동료가 겹치지 않도록 동료 영역의 오른쪽 여백을 확보했다. 실제 Safari 단말 검증은 포함하지 않는다.

`UI_QA_DIR=/절대경로/qa/roomy-buttons node scripts/capture-visual-pass.cjs`로 캡처를 재생성할 수 있다. PNG는 로컬 서버를 실행하고 `node scripts/export-ui-b.cjs`로 다시 출력한다. UI_BASE_URL, UI_CHROMIUM_PATH를 설정할 수 있다. 테스트와 Pages 빌드는 기존 명령을 따른다.
