# 데일리 전투 효과 제거 — 2026-11-23

사용자 요청에 따라 날짜별 전투 보정을 폐지한다. 새 당직과 이어하기 모두 기본 규칙을 사용한다.

- 피해, 적 체력·방패·속도, 처치 SP, 소환·강화 비용, 스킬 재사용 시간, 시작 보급 보정을 적용하지 않는다.
- 로비의 오늘의 변주 및 전투 변주 안내·게시판 진입점을 숨기고 비활성화한다.
- 기존 저장의 카탈로그 ID는 읽기 호환성을 위해 유지한다. 실제 전투 활성 플래그는 false로 복구한다.
- 옛 저장에 이미 곱해진 적 체력·방패·속도와 남은 스킬 쿨다운은 기본 배율로 환산한다. 원본 저장 객체를 변경하지 않고, 새 저장부터는 반복 환산하지 않는다.
- 이미 획득한 SP, 보드 직원, 보상 룰렛의 확정 결과는 회수하거나 재추첨하지 않는다.
- 수료 선물·스토리·상시 밸런스·5웨이브 룰렛은 유지한다.
