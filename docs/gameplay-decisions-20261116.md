# 전투 선택 개선과 단계별 E2E · 2026-11-16

이 변경은 `b4ba605`의 공개 게임 점검 후속입니다. 합성의 위험·이득 → 배치·상성 피드백 → 초반 전략 선택 순서로 구현하고 각 단계 직후 Chromium에서 실제 조작을 검증했습니다. 공개 배포는 변경하지 않았습니다.

## 1. 합성의 교환 조건을 미리 읽기

직원 선택 및 드래그 시 다음 등급, 실제 성공/실패 확률, 종류 랜덤/유지, 빈자리 확보, 평타 총화력이 줄 수 있다는 점을 함께 표시합니다. 5등급 진입에는 스킬 해금을 명시하고, 실패 시 이동 직원 소멸과 다음 유료 소환 반값을 안내합니다. 성공 보장과 종류 유지의 소비 조건은 기존 로직을 사용합니다. 선택을 방해하는 확인 모달은 추가하지 않았습니다.

1단계 E2E는 320×568, 390×844, 430×932, 1440×1000에서 터치 합성 실패 → 저장/새로고침/이어하기 → 키보드 보장 합성 성공 → 실제 터치 드래그 합성 성공을 검사했습니다. 안내가 보드 영역 안에 들어오는지도 확인했습니다. [stage1/report.json](../qa/gameplay-20261116/stage1/report.json)

## 2. 배치와 상성을 선택한 직원에 연결

- 인사담당은 실제 평타 공격에 적용할 수 있는 상하좌우 직원을, 봉투는 상하좌우의 다른 5등급 이상 직원을 표시합니다. 기절 중인 지원은 중단으로 안내하고 효과 중첩 제약도 설명합니다.
- 유령 배달부는 실제 선두 방향과 훈련 단계의 관통 폭을 점선으로 표시합니다. 평타 관통과 5등급 스킬의 방패 무시를 구분합니다.
- 지뢰공은 해당 직원이 이미 설치한 지뢰의 실제 폭발 반경을 표시합니다. 안내 자체가 지뢰/직원 식별자를 생성하거나 전투 상태를 바꾸지 않습니다.
- 현재 전투 중인 군단장 또는 이미 정찰된 군단장의 기존 공략을 표시합니다. 알려지지 않은 군단장을 미리 추첨하거나 공개하지 않습니다.
- 합성 후보가 있으면 합성 안내를 우선합니다. 전열 정비 중에는 합성 가능성을 안내하지 않고 빈 칸 이동/전투 재개 후 합성이라는 제약을 표시합니다.

2단계 E2E는 네 크기에서 기존 합성 흐름에 더해 실제 인접 쿨다운 지원, 방패 무시 스킬, 군단장 7종의 공략 일치, 지뢰 반경/저장 복원을 검사했습니다. 캡처에서 발견한 보스 예고와 안내의 겹침도 수정해 교차하지 않는지 확인했습니다. [stage2/report.json](../qa/gameplay-20261116/stage2/report.json)

## 3. 첫 보스 보상부터 전략을 고르기

일반 당직의 새 5웨이브 보상에서 SP / 전략 / 합성 보험 또는 왕좌 수리를 제시합니다. 생명이 줄었다면 수리를 대안으로 유지합니다. 전략 카드를 누르면 기존의 연쇄 잔광·정산 특근·비상 방벽 중 선택할 수 있습니다. 각 카드에는 효과와 플레이 방향을 함께 적었습니다.

정산 특근은 명단에 서기가 있거나 회계사를 장착한 경우에만 선택할 수 있으며, 조건이 없으면 이유를 표시한 비활성 카드로 남습니다. 선택 화면에서 돌아오거나 새로고침해도 자동 선택·보상 지급이 발생하지 않습니다. 선택 후에는 기존과 동일하게 당직 전략을 하나만 적용하고 다음 웨이브로 진행합니다. 이미 저장된 보상 카드/전략은 재추첨하거나 덮어쓰지 않습니다.

피해·수입 배율, 방어 횟수, 합성 확률, 가격 및 SP 지급량은 변경하지 않았습니다. **전략의 등장 시점과 첫 보상의 구성은 의도적으로 변경했습니다.** 따라서 숫자가 같아도 실제 난도와 플레이 선택은 달라질 수 있습니다.

3단계 E2E는 네 크기에서 세 전략 각각의 취소, 선택 전 새로고침, 선택 후 새로고침, 실제 효과, 중복 적용 방지, 경제 전략의 불가 조건을 검사했습니다. 기존 CSS가 숨긴 카드를 계속 표시하던 문제와 작은 화면에서 세 번째 전략 카드가 스크롤 조상에 가려지는 문제를 캡처로 발견해 수정했습니다. 최종 검사는 모든 전략 카드가 스크롤 없이 조상의 가시 영역 안에 들어오는지도 확인합니다. [stage3/report.json](../qa/gameplay-20261116/stage3/report.json)
