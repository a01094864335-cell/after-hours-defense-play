# 세부 화면 디자인 적용

2026-11-02 승인된 메인·전투 화면의 자주색 패널, 연보라 테두리, 호박색 주요 버튼을 세부 화면까지 확장했다. `detail-ui.css`는 기존 `enamel` 레이어 마지막에서 세부 화면을 꾸민다. 기존 컨트롤, ID, 이벤트, 저장·구매·훈련·채용 규칙은 유지한다.

## 적용 화면

- 상점: 채용팩, 개별 아이템, 지갑, 구매 상태, 채용 결과.
- 직원 도감: 채용 직원, 미채용, 지원 영웅, 편성 명단, 직원·지원 영웅 상세, 봉인된 인사기록, 편성 변경.
- 훈련소: 직원·용병 탭, 레벨·효과·잠금 상태, 고정 훈련 버튼.
- 기록·편성 보관함, 이야기 목록과 재생, 매일 변주 목록.
- 메뉴·오디오 설정, 근무 안내, 저장 백업·복원.
- 장비, 보너스·대상 선택, 일시정지, 종료 확인, 군단장 경고, 결과 보고서.

구매 카드는 이미지·설명을 첫 행, 구매 버튼을 둘째 행에 둔다. 모달의 제목과 닫기 버튼은 유지하고 내용만 스크롤한다. 상세·훈련 화면의 주요 액션은 스크롤 내용과 분리한다. 옛 도감 프레임 pseudo-element는 제거해 테두리 중첩을 막는다.

## 텍스트 배치 기준

아래는 390px 화면 기준이며 320px에서도 유동 배치한다. 글자 수는 번역 제한이 아니라 참고치다. 제어판에 텍스트를 구워 넣지 않고 시스템 글자로 유지한다.

| 영역 | 텍스트 가용 크기 / 서체 | 줄바꿈 |
| --- | --- | --- |
| 모달 제목 | 약 260×60px / 22px, 줄높이 30px | 최대 2줄. 닫기 버튼 40×40px는 별도 고정 |
| 카테고리 탭 | 3개일 때 약 95×36px / 12px | 2줄 허용, 최소 버튼 높이 42px |
| 상품명·설명 | 약 220px 폭 / 15px·12px | 설명은 여러 줄 허용. 구매 버튼 영역 침범 불가 |
| 구매 버튼 | 약 290px 폭 / 13px, 금액 17px | 금액·단위·수량 한 줄 권장. 긴 번역은 높이 확장 |
| 직원 이름 | 약 175px 폭 / 17px | 1줄 권장, 긴 이름은 줄바꿈 허용 |
| 직원 직무 | 약 175px 폭 / 11px | 2줄 허용 |
| 편성 초상 이름 | 약 45×14px / 10px | **두 줄 불가**. 짧은 표시 이름 사용 |
| 상세 이름 | 약 290px 폭 / 24px | 긴 번역은 줄바꿈 허용 |
| 주요 액션 | 약 320px 폭 / 15px, 줄높이 22px | 1줄 권장. 필요 시 버튼 높이 확장 |
| 설명·안내 | 약 300px 폭 / 13px, 줄높이 약 21px | 여러 줄 허용, 내용 스크롤 |
| 훈련 상태 | 54px 폭 / 9px, 줄높이 15px | 2줄 허용 |
| 닫기 아이콘 | 19×19px, 터치 영역 40×40px | **텍스트·두 줄 불가**. 접근성 이름으로 기능 설명 |

## 검증

- 기존 런타임 테스트 30개 통과.
- 320×568, 390×844, 430×932에서 32개 상태씩 96개 화면 검사. 스크롤 끝도 캡처했다. 가로 넘침·뷰포트 이탈·실행 오류 없음.
- 캡처를 직접 검토해 상점 구매 버튼과 상품 설명 중첩, 도감 장식 프레임 잔재, 명단 위 빈 공간, 비활성 보너스 버튼의 대비를 수정했다.
- 세 크기에서 실제 버튼 클릭으로 아이템 구매 시 20코인 차감, 훈련 레벨 증가, 직원 상세·뒤로가기·미채용 이동, 채용 결과 열기를 확인했다.
- `scripts/check-play-design.cjs`는 이전 이미지 URL 대신 실제 배경·테두리·굵기로 선택 탭 구분을 확인한다. 결과 삽화·제목 충돌도 세 크기에서 확인한다.
- `scripts/check-detail-ui.cjs`는 상품 이미지·설명과 구매 버튼이 겹치지 않는지 및 위 동작을 검증한다. 테스트 데이터는 별도 GM 브라우저 컨텍스트에만 사용한다.
- 캡처와 검사 결과: `qa/detail-ui/after`, `qa/detail-ui/interactions.json`.
