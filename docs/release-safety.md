# 출시 안정성 보완 · release-safety-1

기준 통합 배포 `82d1bea` 위에서 기존 게임 규칙·애셋을 유지하며 수정했다.

- **미지급 정산:** 지급 전 결과 스냅샷을 기록하고 재접속 시 정산을 재시도한다. 저장 쓰기가 전부 실패하면 최신 결과는 기록할 수 없으므로 마지막 정상 전투 저장을 유지한다. 지급 실패 상태의 수료 전환·화면 이동에서도 그 기록을 지우지 않는다.
- **원자적 수료 보상:** 기본·군단장·수료 보너스와 수료 플래그를 한 메타 저장으로 처리한다. 이미 기본 보상만 지급한 기록의 수료 보너스 재시도도 지원한다. 요약·상세는 같은 합계를 표시한다.
- **단일 저장 탭:** Web Locks API로 한 탭만 지갑·진행 저장을 갱신한다. 다른 탭은 안내 화면에 머물며, 소유 탭을 닫고 다시 연결하면 최신 저장을 읽는다. 잠금 미지원 브라우저는 안전하지 않은 동시 저장 대신 브라우저 업데이트 안내를 표시한다.
- **회전:** 높이 600px 이하 가로 화면에서는 세로 회전 안내를 표시하고 전투를 정지한다. 세로로 돌아와도 자동 재개하지 않으며 계속하기를 눌러야 한다.
- **짧은 세로 화면:** 조작부를 압축하고 전투 보드 공간을 우선한다. 320×568의 보드는 140→276px, 360×640은 193→348px로 커졌다. 모든 주요 조작의 가로·세로 화면 내 배치를 검사한다.

## 검증

```sh
python3 -m unittest discover -s tests -v
```

Python Playwright와 `/usr/bin/chromium`이 필요하다. 테스트는 임시 localhost 서버와 격리된 브라우저 컨텍스트를 사용한다.

13개 회귀 검사: 일반/수료 보상 중복 방지, 실패한 구매의 재화 보존, 미지급 결과 재접속 복구, 저장 전체 실패의 체크포인트 보존, 같은 화면 지급 재시도, 실제 수료·이동 실패 경로의 체크포인트 보존, 기존 부분 지급 수료 기록, 두 탭 충돌 방지/재연결, 정상 이어하기/훈련 복원, 회전 정지/명시적 재개, 작은 화면 배치, 군단장 7종 경고/스킬 효과/처치 보상.

저장 오류는 테스트에서 주입한다. 군단장·수료 상태도 통제된 상태로 구성하므로 전체 자연 플레이·밸런스 검증을 대신하지 않는다. 실기기 Safari/Chrome, 오래된 브라우저 지원 범위, 장시간 무한 모드 성능은 별도 확인 대상이다. 로컬 저장 특성상 브라우저 데이터를 삭제하거나 모든 저장이 실패한 순간의 최신 진행까지 복구할 수는 없다.
