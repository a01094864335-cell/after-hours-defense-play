# 글로벌 코인 가격 변경

사용자가 승인한 추천값을 실제 구매 로직과 상점 표시에 반영했다. 배포 키: `coin-prices-1`.

| 상품 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 채용팩 | 30 | 120 |
| 등급 합성권 | 8 | 20 |
| 종류 합성권 | 12 | 30 |
| 마왕 깨우기 | 20 | 50 |
| 결계 계약직 | 25 | 150 |
| 야간 회계사 | 30 | 200 |
| 비상 대응반 | 40 | 250 |

상점의 채용팩 가격 안내는 실제 `PACK_PRICE`에서 갱신하도록 연결했다. 보유 코인·아이템·이미 고용한 용병과 지정 채용 3포인트, 영구 훈련 비용은 변경하지 않는다. 기존 고용에 차액을 청구하지 않는다.

광고 기능은 이번 가격 변경에 포함하지 않았다. 신규 직원·지원 용병 9종은 [제안 문서](character-expansion-proposal.md)에만 정리했으며 아직 구현하지 않았다.
