# 단계 보상·합성 실패 회복·3배속

## 1. 5단계마다 보상 양/질 증가

매 보상에서 **하나만 선택**한다. 단계가 오르면 기존 선택지를 강화하고 15단계 이후 선택지를 추가한다.

| 돌파 | SP 기본 하한 | 생명 회복 | 합성 보장 충전 | 추가 선택지 |
|---|---:|---:|---:|---|
| 5 | 150 | +1 | 1회 | 없음 |
| 10 | 300 | +2 | 2회 | 없음 |
| 15 | 450 | +3, 최대3 | 2회 | 원하는 직군 장비+1 / 무작위 편성 직원3등급 |
| 20 | 600 | +3, 최대3 | 3회 | 원하는 직군 장비+2 / 원하는 편성 직원4등급 |
| 25 | 750 | +3, 최대3 | 3회 | 원하는 직군 장비+3 / 원하는 편성 직원4등급 |
| 30 이후 | 900부터 5단계마다150 증가 | +3, 최대3 | 3회 | 원하는 직군 장비+3 / 원하는 편성 직원5등급 |

SP 선택지는 기본 하한과 현재 기본 비용에서 소환할 때마다10 SP씩 증가하는 비용까지 합산한 2/3/4/5회분 중 큰 값이다. 20단계 이후에는 최소 5회분이다. 소환 비용이 증가해도 후반 SP 보상이 무의미해지지 않게 한다. 반값 쿠폰은 SP 보상 계산에 포함하지 않는다.

합성 보장은 기존 잔여 횟수에 더하는 것이 아니라 표시된 횟수까지 충전한다. 무효 합성에는 소모되지 않는다. 기존 boolean 저장값 true는1회, false는0회로 호환한다.

장비 강화는 SP를 쓰지 않고 선택한 직군 전체에 적용한다. 기존 최대 Lv.5를 넘지 않는다. 직원 지급은 편성한 다섯 종류 안에서만 이뤄지며 빈자리가 없으면 비활성이다. 장비/직원 대상 선택에서 뒤로 가도 보상 선택권을 소모하지 않는다. 한 보상을 받은 뒤에는 중복 수령할 수 없다.

연수는 기존대로10단계에서 수료하며 해당 수료 보상은 유지한다. 일반 당직에서는10단계 보너스를 받을 수 있다.

## 2. 합성 실패 후 다음 소환50% 할인

- 전투에서 SP로 소환하는 직원에 적용한다. 상점의 영구 채용팩/용병 가격은 유지한다.
- 합성 확률 판정으로 직원1명이 사라졌을 때 할인1회를 부여한다. 조건에 맞지 않는 합성이나 최대등급 합성 시도에는 부여하지 않는다.
- 다음 **성공한 소환**에만 적용한다. 자리가 없거나 SP가 부족하면 보존한다.
- 실패가 반복돼도 할인율은50%이며 중첩하지 않는다.
- 예: 기본100 SP → 실제50 SP 차감 → 다음 기본 비용110 SP. 비용 증가 자체를 반으로 줄이지 않는다.
- 소환 버튼에 '반값 소환'과 실제 비용을 표시한다. 사용 전/후 상태를 자동 저장하고 같은 판 이어하기에서 복구한다. 새 판에서는 초기화한다.

## 3. 배속

1→2→3→1로 순환한다. 이동·생산·전투·스킬 시간은 기존 게임 시간 배율을 따른다. 일시정지 상태 자체는 변경하지 않는다. 설정 변경을 저장하고 이어하기에서 복구한다. 기존1/2배속 저장과 호환한다.
