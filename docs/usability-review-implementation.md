## 검증

- `python3 -m unittest discover -s tests -v`: 기존 출시 안전성 13개 + 사용성 회귀 6개 = 19개 통과.
- 회귀 항목: 스크롤된 상점에서 결과 모달 표시, 키보드 순환·Escape, 중복 결과, 네 자리 SP, 320px 카드3개, 장비/훈련 고정 정보, 결과 첫 화면 행동, 군단장 표시 크기.
- 320×568 / 360×640 / 390×844 / 1280×900 및 844×390 가로 회전 안내 캡처. 어려운 전투·결과·구매 상태는 격리 브라우저에 상태를 주입해 확인.
- 밝은 글자/민트/비활성 글자와 지정 단색 바탕 5쌍의 sRGB 대비는 11.46~12.96:1. 삽화·SVG 전체에 대한 접근성 인증을 의미하지 않는다.
- 브라우저 자동화에서 키보드·반응형 배치를 확인했다. 실제 기기의 터치·스크린리더 검증은 이 결과에 포함하지 않는다.

스타일은 `usability.css`가 기존 스타일 뒤에서 명시적으로 우선한다. 짧은 화면 안내 영역은 높이44px로 늘리되 기존 회귀 테스트의 전투판 최소240px와 필수 조작 버튼 노출을 함께 검증한다.
