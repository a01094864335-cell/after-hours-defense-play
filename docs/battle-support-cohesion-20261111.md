## 동작 범위

지원 영웅의 자동 발동·피해·수입·주기·훈련·저장 규칙은 바꾸지 않았다. `drawMercenary`의 기존 장식용 캔버스 출력 대신 실제 `activeMerc` 상태를 읽는 DOM 배지를 사용한다. 준비 중에는 기존과 같이 선택된 지원을 보여준다. 실제 효과·이펙트와 지원 제스처 상태는 원래 경로를 유지한다.

미선택에서 직원을 누르면 원래 얼굴·스킬 이름·등급·사용 버튼으로 돌아온다. ★5 미만 잠금, 기절, 충전, 준비, 일시정지 상태와 원래 `useSkill` 핸들러는 유지한다. 안내를 클릭한다고 자동으로 직원을 선택하거나 스킬을 사용하지 않는다.

보드 좌표, 선택 판정, 투사체, HUD/보드/스킬/소환/아이템의 승인된 영역 비율은 유지했다. 신규 CSS는 `battle-cohesion.css`에 한정하고 배포 빌드에 포함했다. 5웨이브 보상 재설계는 별도 논의이므로 이번 변경에 포함하지 않았다.
