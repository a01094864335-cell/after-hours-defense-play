# 디자인 리뷰 수정안 반영

기준: 2026-10-19 2차 디자인 리뷰의 「개선 아이디어 · 시각 디자인만」.

- 공통: 정보 패널의 황동 장식 채도를 낮추고 본문·보조 글자 대비, 숫자 자릿수 정렬, 상태 민트색을 통일했다.
- 로비: 왼쪽 로고·오른쪽 고비 구도를 유지하고 그림자, 편성 초상 바닥선, 바로가기 아이콘과 레이블, 이어하기 글자를 정리했다.
- 전투: 보드 주변 배경을 낮은 채도로 조정하고 SP 수치와 보조 액션의 강조를 구분했다. 일시정지 삽화는 비율을 보존한다.
- 명단·장비: 초상과 이름·역할·상태 기준선을 정리하고 장비 카드의 여백을 줄였다. 미채용 실루엣은 기존 공개 정보 범위에서 톤만 조정했다.
- 상점·훈련: 이미지 정렬, 팝업 여백, 제목·본문·잠금 효과 가독성, 훈련 패널과 버튼의 색상·모서리를 통일했다.
- 결과: 삽화를 줄이고 제목·배지의 공간을 확보했다. 아이콘·항목·수치 열을 맞추고 핵심 숫자를 26px로 확대했다.
- 안내·프롤로그: 안내 카드에 모션 캔버스도 이미지와 같은 크기로 표시한다. 본문 줄바꿈과 화자·대화 패널의 대비를 정리했다.

`visual-polish.css`를 `release-safety.css` 앞에 배치했다. 짧은 세로 화면의 전투판·버튼 크기 보정은 기존 안전성 스타일이 우선한다. 게임 규칙·저장·보상·화면 이동 로직은 변경하지 않았다.

검증: 기존 출시 전 회귀 테스트 13개 통과. 320×568, 390×844, 1280×900에서 로비·안내·훈련·명단·상점·전투·결과 화면 21장을 캡처해 확인했다. 결과 화면은 연수 수료 상태를 주입한 시각 확인이다.
