# 직원 외형·흰 테두리·보드 크기 검수

기준 소스: `80facdbd65ad977d5d7c27f573c8fc8a914412f9`. 사용자 검토로 확정된 캐릭터 개선 내용이다.

## 외형

- 뽀득의 6포즈에 생겼던 사람형 몸통·다리·발을 제거하고 하나의 둥근 슬라임으로 수정했다.
- 루프는 짧은 꼬리가 있는 둥근 부유 유령으로 정리했다. 기존에도 다리는 없었으므로, 다리를 제거했다고 설명하지 않는다.
- 나머지 직원 15명×6포즈는 공통 얼굴·설정 문서·이전 몸체와 비교했다. 몽실·찰칵은 모든 포즈에서 다리 없는 몸체, 실비는 거미 배와 여러 다리, 나비는 날개, 덥석은 상자 몸체를 유지한다. 덥석의 작은 발은 기존 몸체에도 있으므로 임의로 제거하지 않았다. 다른 15명의 원화 픽셀은 변경하지 않았다.

## 테두리

찌릿·덥석·실비·찰칵의 원화에는 다른 13명과 달리 흰 바깥 테두리가 없었다. `Motion.draw`에서 이 네 ID에만 알파 실루엣을 바탕으로 흰 테두리를 그린다. 보드는 1.25 CSS px, 큰 컷인은 높이에 비례한 테두리다. 기존 흰 테두리가 있는 원화에 테두리를 중복 적용하지 않는다. 마스크는 포즈·크기·원화 해시별 캐시이며 최대 48개/16 MiB로 제한한다.

## 보드 크기

세로 높이만 맞추지 않고 대기 포즈 너비×높이의 제곱근으로 시각적 크기를 맞춘다. 각 캐릭터는 6포즈 전체에서 한 배율을 사용하며, 좌우 바닥 기준점과 모든 포즈의 최대 경계로 칸 안전 여백을 지킨다. 둥근 슬라임·넓은 상자/거미·부유 유령을 사람형 비율로 늘리지 않는다. 게임 좌표·판정·수치·저장 구조는 바꾸지 않았다.

후속 검토에서 고비가 너무 크게 보인다는 의견을 반영해, 고비만 보드 배율을 0.88로 조정했다. 59px 칸/84px 행에서 표시 높이는 약 58.1px에서 51.1px로 줄어 브릭 약 51.5px와 가까워진다. 원화·얼굴·컷인·메뉴 크기와 다른 16명의 배율은 그대로다.

## 검증

- 최종 안정된 파일 기준 Node 3261/3261 통과.
- 배포 빌드 성공: 948파일, 이야기 156패널.
- 실제 `Motion.draw`·`BattlePresentation.staffSize`를 native Canvas에서 실행해 17명×6포즈×4칸 크기×좌우 반전 816조합을 검사했다. 빈 렌더·칸 좌우 침범·높이 안전 여백 실패 0건.
- 새 두 아틀라스와 fallback/manifest 해시 일치. 다른 15명의 픽셀은 그대로다. 직원 아틀라스 합계 3,849,630B, RGBA 픽셀 추정 42,308,200B.
- Chromium은 실행 환경의 socket 권한 오류로 시작하지 못했다. 실제 브라우저 화면·상호작용 smoke 검사는 이번 환경에서 실행하지 못했으며, 아래 미리보기를 브라우저 스크린샷으로 표시하지 않는다.

검토 이미지: `qa/character-form-20261111/body-comparison.png`, `board-comparison.png`, `corrected-poses.png`. 같은 그리기 코드를 사용하는 native Canvas 렌더 비교이며, 공개 게임의 캡처가 아니다. 로컬 브라우저 제한 때문에 브라우저 smoke 결과는 GitHub Actions의 해당 배포 커밋 검사에서 확인해야 한다.
