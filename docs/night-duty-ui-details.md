# 야간 당직 UI 디테일 개선

2026-11-04. 최종 베이스는 원격 메인 `2b59d98`이다. 새 튜토리얼 선택 수정과 배포 브라우저 게이트까지 포함한다. 다른 세션에서 추가한 입사 이야기, 튜토리얼 대화·목표·전장 배치, 귀여운 마왕 삽화를 포함한 최신 코드를 그대로 기반으로 삼았다.

## 바뀐 표현

- **오늘의 변주:** 기존 `#daily-label`, `#daily-effect`를 별도 텍스트 열에 모았다. 실제 규칙의 효과 수치가 로비에서 바로 보이고, 유리/불리/복합 분류에 따라 작은 색 차이를 준다. 연수 중에는 연수의 기본 규칙 안내가 그대로 보인다. 15종 상세 목록은 기존 버튼으로 연다.
- **직원 사원증:** 초상과 이름·직무·역할 영역은 유지하고 직원 고유 색상의 얇은 왼쪽 선, 작은 사원 번호, 편성·채용 상태의 도장 표현을 더했다. 이름·번호·상태는 이미지에 굽지 않고 실제 텍스트다. 미채용 상태의 이름·능력 공개 범위는 그대로다.
- **지원 슬롯:** 빈 자리는 계약서 아이콘과 점선으로 표시한다. 선택하면 기존 초상과 인사기록의 이름을 표시한다. 로비에서 슬롯을 누르는 기존 지원 선택 동작을 사용한다. 충분한 공간에서는 오른쪽 세로 슬롯, 짧은 그림 영역에서는 왼쪽 가로 슬롯으로 배치해 고비/바로가기와 분리한다.
- **상점:** 상품 이미지 영역을 조금 키우고 설명/가격 행은 분리한 채 유지했다. 채용 확률과 보장·중복 규칙은 구매 버튼 앞의 native details에 둔다. 요약에는 실제 `RECRUIT_SUPPORT_RATE`의 일반/지원 비율을 표시하고, 펼치면 원래의 모든 설명을 읽을 수 있다. 가격·보장·채용·아이템 소비 규칙은 바꾸지 않는다.
- **반응:** 버튼을 누를 때 1px 눌림과 짧은 명암 반응을 준다. 고비는 기존 정지 이미지를 최대 2px 천천히 움직여 호흡을 표현한다. 눈·열쇠를 따로 움직이는 새 스프라이트는 추가하지 않았다. 절전 모드, 동작 줄이기 설정, 팝업 표시, 백그라운드에서는 호흡을 멈춘다.

배경과 실제 컨트롤 공간을 공유시키지 않는다. 기존 단일 `ui.css`의 컴포넌트 규칙을 수정했고, 새 보정용 CSS 파일이나 전투 규칙은 추가하지 않았다.

## 텍스트 크기와 줄바꿈

| 영역 | 기준 | 줄바꿈 |
| --- | --- | --- |
| 변주 제목 | 문맥 10px / 이름 12px | 필요 시 제목 행 줄바꿈 허용 |
| 변주 효과 | 11px, 줄높이 1.55, 유동 폭 | 여러 줄 허용. 생략/고정 높이 없음 |
| 직원 이름 | 17px, 작은 화면 16px | 긴 이름은 줄바꿈하고 카드 높이 증가 |
| 역할 | 10px + 12px 공통 아이콘 | 설명에 따라 줄바꿈 허용 |
| 사원 번호 | 9px monospace | **한 줄 전용** |
| 채용/편성 도장 | 10px, 작은 화면 9px, 최대 66px 폭 | 필요 시 줄바꿈 허용 |
| 지원 영웅 이름 | 10px, 기본 슬롯 64px 폭 | 기본 한국어 이름 1–2줄. 긴 번역은 가로 슬롯/짧은 표시 이름 필요 |
| 채용 규칙 요약 | 12px | 긴 번역은 줄바꿈, 본문은 여러 줄 허용 |

새 텍스트 애셋은 없으며 기존 아이콘을 재사용한다.

## 검증과 범위

- 배포 패키지의 새 브라우저 게이트 **8개** 통과. 실제 튜토리얼 선택·소환·스킬·일시정지·저장/복원·중복 보상·실패 구매·회전 상태 확인.
- 기존 런타임 테스트 **54개** 통과. 채용 이야기·튜토리얼·정사각형 전장·저장 테스트 포함.
- 기본/스크롤 끝 **133개** 화면 snapshot에서 버튼 넘침·텍스트/이미지 교차·모달 경계 검사 통과.
- 320×568, 375×667, 390×844, 430×932에서 15개 변주 × 이어하기 유무, 총 **120개** 조합의 실제 효과 문구와 영역 교차 확인.
- 별도의 8개 모바일 크기 × 이어하기 유무 **16개** 로비 조합 확인. 짧은 그림 영역에 맞춰 슬롯과 로고 배치를 보정했다.
- 긴 한국어/영문과 130% 글자 크기 **12개** 조건의 상단·하단 확인.
- 지원 선택, 직원 탭/상세, 채용 설명 펼치기, 실제 아이템 구매(20코인 차감) 동작 확인.
- 동작 줄이기/절전/팝업에서는 모션이 `none`, 일반 모드에서는 `gobi-breathe`임을 확인.
- 캡처를 눈으로 검토했다. 최신 메인의 로비에는 고비와 지원 버튼의 box 교차가 두 크기에서 이미 있었고, 이번 배치에서 해소됐다.

`ui-layout-audit.cjs`는 fullscreen 이야기의 absolute 배경을 일반 패널의 본문 행으로 오인하지 않도록 수정했다. 헤더·대사·버튼의 실제 글자/컨트롤 검사는 유지하며, border 없는 fullscreen 영역은 viewport 경계와 맞닿는 것을 허용한다. 이야기 화면의 연출 코드는 수정하지 않았다.
