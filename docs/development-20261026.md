# 2026-10-26 전체 검토 반영

기준 버전: 공개 저장소 d65e6a2. 현재 실행 소스와 배포 기준은 after-hours-defense-play로 통일한다. 다른 소스 체크아웃에서 생성한 오래된 실행 파일을 통째로 덮어쓰지 않는다.

## 화면과 연출

- GM 화면은 본문 높이를 줄이는 이전 규칙을 최종 스타일에서 해제하고, 앱 내부 높이에서 GM 도구용 52px을 별도로 확보한다.
- 전투 상단·소환·스킬·아이템은 고정 영역, 보드는 남은 영역에 맞춘다. 짧은 화면은 간격을 줄인다. 작은 보드의 조작 대안인 직원 목록을 유지한다.
- 스킬은 기본적으로 0.6초의 작은 배너를 쓴다. 설정에서 큰 연출을 선택해도 같은 캐릭터의 반복 연출은 축소한다. 큰 연출은 0.85초이며 전투 시간은 멈추지 않는다.
- 군단장 등장 경고·공격 예고가 있을 때 컷인은 숨겨 위험 신호를 우선한다. 마왕의 기존 등장 연출과 캐릭터성은 유지한다.
- 일반 성공 알림은 4초 후 정리한다. 저장 오류는 8초간 보이며 전투에서는 하단 안내에 전달해 보드를 가리지 않는다.
- 1→2→3→1배속과 표시를 일치시킨다.

## 이야기 자산

- 추가 이야기 19편 76컷을 최대 900×1200의 WebP(quality 82)로 변환했다. 원본 약 171.36MiB → 약 10.27MiB, 약 94.0% 감소.
- 매 판 이야기 표시·이전/다음·스와이프·첫 발견 보상 정책을 유지한다.
- 현재 컷과 다음 컷을 읽고, 도감 표지는 지연 로딩한다. 로딩 실패에도 대사는 유지하고 다시 읽기 버튼을 제공한다.
- 원본 PNG는 저장소에 보관하며 Pages 산출물에서는 제외한다. 재생성과 수치 자료: scripts/optimize-stories.py, story-optimization.json.

## 채용 경제

- 팩 가격 120코인, 일반 90% / 지원 10%를 유지한다. 일반 17종·지원 7종은 각 풀 안에서 균등하다.
- 미보유 지원을 만나지 못한 팩을 누적한다. 9회 누적 상태의 다음 팩은 미보유 지원 중 균등한 1명을 확정 지급한다. 중복 지원도 누적 실패로 센다.
- 미보유 지원 획득 또는 지원 지정 채용 시 누적을 0으로 초기화한다. 지원을 모두 보유하면 보장 누적은 쓰지 않는다.
- 기존 중복 포인트를 그대로 사용한다. 일반 지정은 3포인트, 지원 지정은 10포인트. 새 재화를 만들지 않는다.
- 도감에서 미보유 지원의 역할을 확인해 지정 채용하고, 보유 지원 1명을 선택한다. 지원은 보드 15칸·일반 편성 5칸에 포함하지 않는다.
- 코인·포인트·영웅 지급·보장 누적은 한 번의 저장으로 확정한다. 저장 실패에는 어느 것도 차감하지 않는다.

## 튜토리얼과 성장

- 첫 10웨이브 연수는 날짜에 관계없이 기본 규칙을 적용한다. 이전 저장에서 연수를 이어도 일일 변주는 제외한다.
- 연수 수료 뒤에는 기존 무한 웨이브와 오늘의 변주를 적용한다. 별도 10웨이브 단기 모드는 만들지 않는다.
- 영구 훈련은 직원 / 지원 공통 그룹별 1~30레벨, 코인만 사용, 확정 성공 정책을 유지한다. 현재 공격 배율은 최대 1.8배이며 전투 SP 장비와 곱한다.
- 훈련소의 실제 현재→다음 효과 표시를 유지하고 로비의 훈련 수치도 즉시 갱신한다. 수치 전체를 올리기 전에 현재 인원 기준 반복 검증을 수행했다. 자세한 조건과 한계는 밸런스 문서를 따른다.

## 전투 분석과 반복 목표

- 소환 횟수, 합성 성공/실패, 스킬 사용, 아이템 사용, 마왕 출동·처치·군단장 처치를 별도로 센다.
- 직원별 실제 피해·처치·SP, 감속·스킬 지연·가속·충전 단축·표식 및 공유 피해의 보조 기여를 표시한다. 보조 수치는 같은 적/직원의 누적 대상 시간 또는 추정 추가 피해이며 전체 피해에 중복 합산하지 않는다.
- 지원의 직접 피해, 추가 피해 추정, SP, 생명 방어, 정화·저지를 기록한다.
- 돌파 적 이름·남은 HP 비율·생명 손실을 마지막 12건까지 남긴다. 군단장 처치 시간은 마지막 30건을 기록하며 마왕 처치는 따로 표시한다.
- 결과에 이전 판 도달 차이와 마지막 돌파/합성에 근거한 다음 판 힌트를 표시한다. 확정적인 패배 원인 진단으로 표현하지 않는다.
- 정식 당직의 최고 완료 웨이브와 다음 5단위 목표를 표시하고, 최근 20판의 웨이브·코인·훈련·변주·마왕 도움을 보관한다. 기존 버전에 없던 과거 기록은 추정해서 만들지 않는다.
- 직원 5명 + 지원 1명 편성을 3개 저장한다. 연수 수료 후 사용할 수 있고, 소환된 보드나 진행 중 당직에는 불러올 수 없다.

## 저장과 배포

- 기존 지갑/훈련/영웅/아이템은 유지하고 선택 필드를 버전 1 프로필로 이관한다. 전투 통계는 기존 자동 저장·이어하기·미지급 보상 복구에 포함한다.
- 메뉴에서 JSON 파일 백업 또는 텍스트 복원을 제공한다. 복원 전 코인·보유 영웅·훈련을 미리 보고 명시적인 교체 버튼을 누른다. GM은 백업/복원을 하지 않는다.
- 지갑·진행 전투·미지급 결과를 함께 검증한다. 불완전 가져오기는 이전 값을 복구하는 저널을 남기며, 다음 로드에서 단일 작성자 잠금을 얻은 뒤 복구한다. 서버 계정 동기화 기능은 아니다.
- Pages는 브랜치 자동 발행 대신 검증 → 산출물 패키징 → 배포 작업을 사용한다. 실패한 runtime 작업은 deploy 작업을 실행하지 않는다.
- 원본 PNG·문서·QA·스크립트는 게임 산출물에서 제외한다. 새 JS/CSS는 내용 해시로 캐시를 갱신하며, 배포 커밋을 산출물 매니페스트에 기록한다.

## 검증

- 기존 할인·합성 보장·확장 저장·보상 재지급 방지 회귀 검증 유지.
- 신규 채용 보장·지정 채용·튜토리얼·프로필 이관·이어하기·중복 정산 방지·편성·백업 검증/실패 복구·GM 격리·군단장 시간·이미지 예산·배포 의존성 검증.
- 로컬 실브라우저에서 360×640 GM 전투, 일반 저장 복원/새로고침, 보장 채용/지정 채용, 이야기 로드 실패/재시도, 편성 저장, 3배속을 확인한다. 실제 휴대폰 발열·배터리와 장기간 리텐션은 이 검증만으로 확정하지 않는다.
