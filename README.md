## 출시 안정성 보완

`release-safety-1`: 단일 탭 저장 잠금, 미지급 정산 복구, 수료 보너스 합계,
세로 화면 안내 및 작은 화면의 전투 공간을 보완했습니다.

게임은 HTTPS 또는 localhost에서 실행하세요. 안전한 단일 탭 저장에 Web Locks API를
사용하며, 지원하지 않는 브라우저에는 업데이트 안내를 표시합니다. 다른 게임 탭을
닫은 뒤 차단된 탭에서 **다시 연결**하면 최신 저장을 읽습니다.

미지급 결과 기록이 저장되면 재접속 시 지급을 재시도합니다. 저장 공간 문제로 모든
쓰기가 실패하면 최신 결과까지 보존할 수는 없지만 마지막 정상 전투 저장은 유지합니다.

회귀 검사(Python Playwright와 Chromium 필요):

```sh
python3 -m unittest discover -s tests -v
```

실제 기기의 Safari/Chrome 조작성과 장시간 플레이는 별도로 확인해야 합니다.


### GM 테스트 모드

URL에 `?gm=1&coins=1000000`을 붙이면 테스트용 글로벌 코인으로 시작합니다. 기존 파라미터가 있으면 `&gm=1&coins=1000000`을 추가하세요. `gm=1`에서만 활성화되며 코인은 0~1,000,000,000 정수입니다. 생략하거나 유효하지 않으면 안내와 함께 100,000 코인을 사용합니다.

하단 GM 패널에서 잔액을 바꾸거나 튜토리얼을 건너뛸 수 있습니다. 기존 기록을 복사한 현재 탭의 메모리에서만 구매·훈련·전투가 진행되며 실제 저장 기록은 변경하지 않습니다. 일반 모드의 진행 중 전투는 불러오지 않습니다. 새로고침하면 테스트 변경 사항이 초기화되고, 파라미터를 제거하거나 일반 모드 링크로 돌아가면 원래 기록을 사용합니다. 서버 관리자 인증 기능은 아닙니다.


상점: 채용팩(일반 90% / 지원 10%)과 개별 아이템 구매. 지원 영웅은 직원 도감에서 선택합니다. 자세한 정책은 [상점 정책](docs/shop-system.md)을 참고하세요.

GM 모드에서는 현재 카탈로그의 모든 직원·지원 영웅을 자동 보유합니다. 일반 직원은 5명, 지원 영웅은 1명을 직접 선택하며 기존 편성과 훈련 레벨은 유지합니다. 정상 모드의 보유 기록에는 반영하지 않습니다.
