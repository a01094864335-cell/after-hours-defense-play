# B 에나멜 키캡 UI 애셋 규격

2026-11-02 · 모바일 전용 · 현재 UX 유지 · 시각 부품 라이브러리

## 적용 범위

버튼, GNB 탭, 카테고리 탭, 패널, HUD, 상태 배지, 슬롯, 결과 리본을 B 스타일로 제작했다. 배경·캐릭터·아이템·웹툰은 기존 애셋을 재사용한다. 게임은 enamel-ui.css에서 B 부품을 사용하며 기존 UX와 게임 로직을 유지한다. 전체 화면 시안의 텍스트·수치를 게임 상태로 사용하지 않는다.

`manifest.json`이 좌표의 정본이며 `index.html`에서 모든 상태와 텍스트 영역을 확인할 수 있다. `assets/ui-b`에는 편집 가능한 SVG와 2배 PNG가 있다. assets/ui-v2의 과거 시안은 이력으로 유지한다.

## 실제 게임 연결

index.html이 기존 스타일 다음에 enamel-ui.css를 로드한다. 공개 갤러리는 assets/ui-b/gallery.html이다. 실제 소스·배포 기준과 현재 UX의 연결표는 docs/enamel-b-live-integration.md를 따른다.

## 표시 크기 변경

고정 비율 확대·축소 시 `sx=표시 너비/원본 너비`, `sy=표시 높이/원본 높이`로 safe의 x/w, y/h를 각각 변환한다. 픽셀 일관성을 위해 균일 배율을 우선한다. 너비만 늘려야 하면 PNG의 12px 테두리(2배 파일은 24px)를 9-slice로 고정한다. 44px보다 작은 배지는 6px(2배 12px)을 고정한다. 이때 safe의 왼쪽·오른쪽·상단·하단 여백을 유지하고 가운데 영역만 확장한다. 예: 320×64 primary를 360×64로 확장하면 safe는 24,16,312,28이다. 모서리 리벳을 늘리거나 텍스트를 프레임 전체 중앙에 임의 배치하지 않는다.

## 폰트·다국어 처리

- 한 줄 버튼: 기본 16px/20px, primary 20px/24px. 줄바꿈 금지. 작은 배지는 10px/12px, 상태 배지는 12px/16px, GNB는 11px/16px, 등급은 10px/12px. safe 높이를 초과하는 행간은 금지한다.
- 2줄 primary: 제목 20px/24px, 보조 문구 10px/12px, 간격 4px로 총 40px. 현재 제목·영문 보조 문구·우측 화살표를 유지한다. 달 아이콘을 임의 추가하지 않는다. 화살표 24px와 간격 8px를 오른쪽에 따로 예약하고 제목 영역을 그만큼 줄인다.
- 2줄 알림·프로필·지원 슬롯: 12px/18px 또는 12px/15px 등 safe 높이에 맞춘다. 패널 긴 본문은 14px/22px. line 수와 높이 양쪽 조건을 모두 만족해야 한다.
- 한 줄 영역이 넘치면 먼저 번역 축약, 다음 허용 범위 안 너비 확장. 버튼 폰트를 무제한 축소하거나 임의로 두 줄로 바꾸지 않는다. 수치·가격도 실제 최대 자릿수로 측정한다. 긴 본문은 스크롤 또는 기존 상세 영역으로 처리한다.
- 시스템 폰트와 언어별 폴백을 사용한다. 말줄임을 쓰는 경우 전체 문구를 접근 가능한 이름/설명으로 제공한다. 주요 행동 의미를 말줄임으로 숨기지 않는다.

## 상태와 터치

버튼·탭·슬롯에 default / pressed / disabled / selected 실물 파일을 제공한다. selected는 장착·선택 시만 사용한다. disabled는 파일 교체뿐 아니라 실제 disabled 속성도 설정한다. pressed는 내부 면만 내려가므로 외부 레이아웃·터치 위치를 움직이지 않는다. 포커스는 별도 2px mint outline, hover는 모바일 필수 상태가 아니다. 최소 터치 영역 44×44px, 작은 배지는 비상호작용 요소로만 쓴다. 이미지에는 텍스트를 구워 넣지 않는다.

## 기존 화면 보존 체크

이 저장소에서는 현재 공개 UX를 기준으로 한다. 하단 GNB 3개(직원 도감·당직실·상점), 이야기·기록·훈련소, 오늘의 변주·편성·지원 동료·당직 준비를 유지한다. 초기 저장소의 5개 GNB나 영문 보조 문구를 추가하지 않는다. 상세는 ../../docs/enamel-b-live-integration.md를 따른다.

## 재사용 원본

로비: assets/mobile/lobby-night.png, lobby-gobi.png. 전투: assets/pixel/lobby-background.png 및 직원·용사 스프라이트. 아이템·용병: assets/mobile 및 기존 pixel 원본. 이야기: assets/comic 4장. 배경 변형: assets/ui-v2/background-{lobby,archive,market,result}.webp. 아이콘: assets/ui-v2/icons 21종 + assets/ui-b/icons/menu.svg. 런타임 메뉴에는 menu.svg를 사용하며 gear.svg로 대체하지 않는다.

## 검증과 배포

편집 원본은 assets/ui-b/*.svg이며 대응 PNG는 2배 출력이다. 전체 검증은 `node --test tests/*.test.cjs`, 배포 빌드는 `node scripts/build-pages.cjs /tmp/game-pages`다. Pages artifact에 모든 UI 애셋이 포함되는지 tests/enamel-release.test.cjs가 검증한다.
