# 만화풍 플레이 원본

승인 시안은 `approved-concept.png`, 글자 없는 환경은 `courtyard-master.png`. 나머지 15개 `*-master.png`는 각각 1536×1024, 3열×2행 전신 6포즈 원본이다. 기준은 같은 ID의 `assets/character-portraits/` 얼굴과 이전 전신의 직업 도구다. 생성 후 모자·종족·머리·안경과 프레임 경계를 검수했다.

고비·찌릿은 기존 승인 원본을 유지한다. 재수출은 `python scripts/export-matching-battle-sprites.py`. 적용 범위와 검증은 `docs/comic-battle-20261110.md`에 기록했다.
