# 다리 없는 직원의 몸체 정리

현재 얼굴 초상과 이전 6포즈를 참조해 두 원본을 수정했다. 각 파일은 투명 배경 1536×1024, 3열×2행이다. 이전 원본은 `designs/battle-comic-20261110/`에 유지한다.

- 뽀득: 얼굴 아래에 붙었던 별도 몸통·두 다리·발을 제거하고, 얼굴과 몸이 하나인 둥근 물방울 슬라임으로 정리했다. 하늘색·물방울 볏·눈·분홍 볼·대걸레·노란 양동이를 유지한다.
- 루프: 원래도 다리가 없는 유령이었다. 긴 하체와 두 갈래처럼 보이는 끝을 짧고 하나로 말린 꼬리로 정리해, 둥근 몸체가 떠 있는 형태를 더 분명하게 했다. 우편 모자·초승달·가방·소포를 유지한다.

두 파일 모두 이미지 편집 생성으로 수정했으며, 배경 알파와 6개 칸 경계, 얼굴·직업 도구, 모든 포즈의 다리 없는 형태를 직접 확인했다. 원본을 코드로 다시 그리지 않았다. 내보내기는 기존 `scripts/export-matching-battle-sprites.py`가 이 디렉터리의 두 파일을 우선하며, 나머지 15명의 원본과 내보낸 픽셀은 그대로다.

편집 요구: 기존 얼굴과 만화풍 선·채색·흰 테두리를 유지한다. 각 512×512 칸에 대기·눈깜빡임·준비·공격·스킬·회복을 하나씩 배치한다. 뽀득은 목·사람형 몸통·허리·엉덩이·다리·발이 없는 하나의 둥근 슬라임, 루프는 같은 요소가 없는 하나의 둥근 유령과 짧게 말린 꼬리로 만든다. 직업 도구를 유지하되 몸보다 과도하게 커지지 않게 한다. 배경·바닥·그림자·문자 없이 실제 투명 알파와 넉넉한 칸 여백을 유지한다.
