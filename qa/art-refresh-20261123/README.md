# 채용팩·훈련소 아트 변경 검수

- 채용팩 S2: 성문에서 달려오는 고비와 동료들. 작은 높이에는 별도 가로 구도.
- 일반 영웅 T4: 경비병과 슬라임이 함께 바벨을 들고 고비가 코칭.
- 지원영웅: 회계사의 장부·도장, 치료사의 치유, 코코의 음파 훈련으로 구분.
- 높이 650px 이하에는 가로, 이상에는 세로 구도. 통계·강화 버튼 영역을 확보한 나머지를 채움.
- Shadow DOM의 스타일시트는 문서의 버전 URL을 공유해 업데이트 후 캐시 불일치를 방지.
- 새 이미지 여섯 개를 배포 파일 목록에 명시. PNG 원본은 배포하지 않음.

## 검증

`node scripts/check-approved-training-art.cjs`: 320×568, 390×844, 430×932, 1440×1000. 구매 비용, 역할 전환 시 저장 데이터 불변, 지원 훈련 비용 및 레벨 증가, 새로고침 후 저장, 키보드 전환, 화면 크기 변경, 조작부 가림, 이미지 디코딩, HTTP/JS 오류 검사.

전체 단위 테스트 3,353개 통과. 기존 브라우저 회귀 20개 통과. 최종 스크린샷은 gallery.html 참조. 실제 모바일 기기 검증은 수행하지 않음.

공개 배포 및 main 병합은 수행하지 않음. 밸런스·확률·가격 변경 없음.

배포 산출물: 1,090파일. 원본 및 패키징 E2E는 각각 report.json으로 기록. build.json의 revision은 빌드 시 기준 커밋이며 미커밋 변경을 포함한 로컬 산출물 검증임.
