# 전체 게임 화면 검토

[index.html](index.html)을 열어 변경 전후를 비교한다. 화면 이름 검색, 320·390·430px 전환과 개편 후만 보기 기능이 있다.

`screens.json`은 35종 기본 화면 목록이다. `before/checks.json`과 `after/checks.json`은 실제 캡처 결과다. 개편 후 검사는 버튼 글자 잘림, 화면 밖 조작, 글자·초상 겹침과 스크롤 하단의 조작을 함께 확인한다.

원본 캡처 PNG는 로컬에 보존하고 저장소에는 WebP 사본을 포함한다. 원본과 사본은 동일한 실제 렌더링 장면이며 새 UI를 합성하지 않았다. 모의 잔액과 콘텐츠 해금은 GM의 격리된 테스트 데이터다.
