- shared-controls.js/css로 닫기·뒤로가기·기본·보조·위험 버튼 규칙을 통합.

- 가격·확률·보상·밸런스 변경 없음. main 병합/공개 배포 수행하지 않음.

## 공개 반영 전 CI 보완

전체 CI에서 닫힌 상점의 닫기 버튼 class/data 속성을 같은 값으로 반복 기록하는 회귀를 발견해 조건부 쓰기로 수정했다. 비활성 버튼의 포커스는 브라우저마다 달라, 테스트는 반복 컴포넌트 적용 직후 포커스를 확인하고 비활성 클릭 차단을 별도로 확인한다. 동적 닫기 버튼의 반복 적용 후 속성/자식 변경 0건도 검사한다. 관련 성능/컴포넌트 11개와 배포 산출물 재현 3개 통과. 사용자 요청에 따라 공개 반영 진행.
